# 首頁與卡片

首頁的用意是讓每個人一開啟 Curahold 就看到自己的工作。每個頁面由卡片組成，每個角色都從自己的首頁開始。

## 卡片

| 卡片 | 顯示內容 |
| --- | --- |
| 我的未完成任務 | 你還沒完成的任務，逾期的排在前面 |
| 即將續約 | 在你選擇的天數內續約的客戶及其總金額 |
| 需要關注 | 健康度有風險或需留意的客戶 |
| 失去聯繫 | 一段時間沒有任何動態的客戶 |
| 關係人風險 | 阻礙者和懷疑者，以及沒有核心支持者的客戶 |
| 單一數字 | 一個數值，例如客戶數或總金額 |
| 分布 | 依某個選項欄位劃分的客戶 |
| 團隊負荷 | 每個人的客戶數，以及未完成、逾期和有風險的工作 |
| 連線 | CRM 與試算表同步的狀態 |
| 備註 | 給團隊的簡短公告或連結 |

大多數卡片都能選擇「我的」、「我團隊的」或「所有人的」。卡片只會在檢視者有權看到的範圍內計算：兩個人開啟同一個頁面，如果權限不同，看到的數字也會不同。

## 編輯頁面

管理員使用 **編輯頁面** 新增卡片、調整順序和大小，並選擇哪些角色從這個頁面開始。頁面也可以只對部分角色顯示。

> **提示：** 想確認某個角色看得到什麼，可以在「設定」→ 角色與權限 中使用 **以 … 的身分檢視**。它會以唯讀方式開啟那個人的畫面。
