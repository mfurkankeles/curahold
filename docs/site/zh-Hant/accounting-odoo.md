# Odoo（會計）

來自 Odoo Online、Odoo.sh 或自建伺服器的客戶、發票和收款。

## 讀取哪些內容

客戶（以及軟體中儲存的統一編號、電子郵件和網址）、含到期日和未付金額的發票，以及收到的款項。Curahold 絕不會寫入 Odoo：它無法在那裡建立、變更或刪除任何內容。

## 連接

在**設定 → 資料來源**中找到**會計軟體**，選擇**連接 Odoo**。然後：

1. 在 Odoo 中開啟你的個人檔案 → 偏好設定 → 帳戶安全，建立一個 API 金鑰。
2. 記下你的 Odoo 網址和登入名稱。在 Odoo.sh 或自建伺服器上，還要記下資料庫名稱。
3. 在下方填寫。在 Odoo Online 上，API 存取需要 Custom 方案（Odoo 的規定）。

## 限制與時間

Odoo 沒有公布固定限制；Curahold 維持每秒約兩次請求，避免給小型伺服器帶來壓力。Odoo 19 及之後版本透過 JSON-2 API 讀取，較早版本透過 JSON-RPC 讀取（此時需要資料庫名稱）。每小時讀取一次變更。

## 發生問題時

如果 Odoo 不再接受連接（金鑰或登入被撤銷），該連接會在 設定 → 連接 中標示為「有問題」，並通知管理員一次；在其頁面上選擇**重新連接**。速率限制的回覆不是錯誤：本次執行會停下、記住位置，下次繼續。
