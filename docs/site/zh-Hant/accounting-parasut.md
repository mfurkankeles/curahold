# Paraşüt（會計）

來自 Paraşüt 的客戶、銷售發票和收款。

## 讀取哪些內容

客戶（以及軟體中儲存的統一編號、電子郵件和網址）、含到期日和未付金額的發票，以及收到的款項。Curahold 絕不會寫入 Paraşüt：它無法在那裡建立、變更或刪除任何內容。

## 連接

在**設定 → 資料來源**中找到**會計軟體**，選擇**連接 Paraşüt**。然後：

1. 向 Paraşüt 客服申請公司的 API 存取權限；他們會寄送 client ID 和 client secret。
2. 公司編號在網址列中 uygulama.parasut.com/ 之後。
3. 連同一位 Paraşüt 使用者的電子郵件和密碼一起填寫。密碼只用一次來取得金鑰，不會被儲存。

## 限制與時間

Paraşüt 允許每 10 秒約 10 次請求，每頁回傳 25 列；它沒有「自某時起變更」篩選，因此每次執行都完整讀取清單。對小企業來說只是幾十頁。金額依發票幣別讀取（TRY、USD、EUR、GBP）。

## 發生問題時

如果 Paraşüt 不再接受連接（金鑰或登入被撤銷），該連接會在 設定 → 連接 中標示為「有問題」，並通知管理員一次；在其頁面上選擇**重新連接**。速率限制的回覆不是錯誤：本次執行會停下、記住位置，下次繼續。
