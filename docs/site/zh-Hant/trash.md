# 垃圾桶

在 Curahold 中刪除東西不會馬上生效。被刪除的項目會移到垃圾桶，保留 30 天，期間可以原樣還原。30 天過後，它會連同檔案一起被永久清除。

## 哪些東西會進垃圾桶

| 你刪除的 | 一起移過去的 | 保留下來的 |
| --- | --- | --- |
| 客戶 | 它的記錄（聯絡人、交易等）、時間軸、會議、健康歷史和入口使用者 | 它的任務會以「無客戶」的狀態留在看板上 |
| 任務 | 它的子任務、留言、工時、追蹤者、關聯和檔案 | 其他東西都不受影響 |
| 記錄 | 它的留言和檔案 | 指向它的任務 |
| 時間軸條目或會議 | 只有它本身 | 會議的後續步驟會以任務的形式保留 |
| 頁面、已儲存的報表、自動化 | 只有它本身 | 自動化已經建立的任務 |

復原一次匯入時，這次匯入新增的所有內容會以一個項目移到垃圾桶。

有些東西會直接刪除，不經過垃圾桶：單則留言、單一檔案、一筆工時記錄、已儲存的檢視、webhook 或 API 金鑰。

## 還原

刪除之後，畫面底部的通知會立刻提供 **復原**。之後可以開啟你的選單（左下角），選擇 **垃圾桶**，找到項目後點 **還原**。

它會原樣回來：同一個網址，帶著當初一起移走的所有內容。其他項目和它之間的關聯也會重新接上：客戶的任務會再次指向它，除非這段期間有人把任務改指向其他客戶。如果它曾和 CRM 連結，同步也會繼續。不會通知任何人，也不會送出 webhook：回來不算新消息。

有三樣東西不會回來：已經送出的相關通知，以及客戶入口使用者已開啟的工作階段和一次性連結。他們需要重新登入；從未接受的邀請必須重新寄送。

### 暫時無法還原的情況

- **它所屬的項目也在垃圾桶裡。** 記錄需要它的客戶，子任務需要它的上層任務。Curahold 會告訴你是哪一個；先還原那一個。
- **它所屬的項目已經不存在。** 例如該記錄類型已被移除。這種情況無法還原。
- **它的位置被別的東西佔用了。** 另一個客戶現在使用相同的 CRM ID，或另一位入口使用者使用相同的電子郵件。先修改或移除那一個。

如果它底下有些東西永久失去了所屬的項目，其餘內容仍會回來，訊息會告訴你有幾項沒有還原。

## 誰看得到什麼

- 你看得到也能還原自己刪除的東西。
- 能變更公司設定或管理隱私的人，看得到公司裡刪除的所有東西，並能還原其中任何一項。
- 檢視者席次不能刪除，所以沒有垃圾桶。

## 永久刪除

能變更公司設定或管理隱私的人，可以對任何項目選擇 **永久刪除**。它會連同檔案立刻被清除，沒有人能還原。用來處理無法等 30 天的個人資料刪除要求。

其他東西會在 30 天期滿後自動離開。

## 開發者

每個把東西移到垃圾桶的 `DELETE` 都會回傳一個 `trashId`。列出、還原和永久刪除的方式見 [垃圾桶參考](/docs/zh-Hant/ref-trash/)。
