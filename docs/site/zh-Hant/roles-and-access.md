# 角色與權限

角色決定誰能看到和變更什麼。規則在資料庫中強制執行，而不只是在介面上：畫面上隱藏的內容，在 API、匯出檔案和 AI 連接器中也一樣隱藏。

## 席次

- **完整席次：** 可以查看和變更。
- **檢視者席次：** 只能查看。適合經理和管理階層。

## 內建角色：每個角色能看到和做什麼

| 角色 | 簡介 |
| --- | --- |
| 管理員 | 一切：公司設定、人員、角色、連線、活動紀錄 |
| 團隊主管 | 看得到所有看板；管理團隊、客戶欄位和自動化 |
| 成員 | 自己的工作，以及能存取的客戶 |
| 檢視者 | 只看，不改 |

可以重新命名角色、新增自己的角色，並逐項開啟或關閉權限。

## 客戶存取權

為每個角色選擇它能存取哪些客戶：

- **所有客戶**
- **所屬團隊的客戶：** 所在團隊的客戶，加上自己的客戶
- **只有自己的客戶**

客戶底下的聯絡人、交易和任務都遵循同樣的規則。

## 欄位層級權限

可以對某些角色隱藏某個欄位，或讓他們只能查看不能變更。例如，成員看得到「年度金額」但不能修改，只有管理員看得到「折扣」。

## 以他人身分檢視

在「設定」→ 角色與權限 中，點人員旁的 **以 … 的身分檢視**，就會照那個人看到的樣子開啟 Curahold。這段期間什麼都不能變更，頂端的提示列會帶你回到自己的檢視。
