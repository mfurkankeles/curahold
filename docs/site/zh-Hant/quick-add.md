# 快速新增與快捷鍵

按 **N**（或左側的 **+ 新增 → 任務**、欄位底部的 **新增任務**、手機上底部的 **+**）就會開啟 **新任務** 視窗。標題下方填寫詳細資料：說明、客戶、任務所屬的記錄（交易、協議等）、負責人、截止日期、優先順序、重複、看板與欄位，以及看板專屬欄位。從某一欄開啟時，該欄已經選好；從客戶頁面開啟時，客戶已經選好。

不必一格一格填；照著想到的樣子寫下標題就夠了：

> 續約電話 friday @林怡君 #維途 !high

這一行就填好了欄位：負責人林怡君、客戶維途交通、截止日期週五、優先順序高。從標題填入的欄位會顯示 **取自標題**。手動修改某個欄位時，對應的字會從標題中移除，欄位保留你的選擇。按 **Enter** 新增任務；在其他欄位中則按 **Ctrl Enter**（Mac 為 ⌘ Enter）。

## 可以寫什麼

除了土耳其文以外，所有語言中表示日期、重複和優先順序的詞都用英文書寫。

| 內容 | 寫法 | 範例 |
| --- | --- | --- |
| 截止日期 | 日常用語 | today, tomorrow, friday, next week, weekend, end of month, nov 15, 15.11, in 3 days |
| 人員 | @ 加姓名 | @林怡君、@王志明、@me |
| 客戶 | # 加名稱 | #維途、#港線銀行 |
| 優先順序 | ! 加等級 | !urgent, !high, !low |
| 重複 | every … | every day, every week, every monday, every 2 weeks, monthly |

在中文句子中，請在以 @ 或 # 開頭的詞前後加一個空格。

- 輸入 **@** 或 **#** 會開啟清單；用方向鍵選擇，按 **Enter** 或 **Tab** 確認。
- 標籤上的 **×**：把人員、客戶或優先順序從這一行移除。被讀成日期或節奏的詞會留在標題中（加上引號）。如果某個詞絕不該被讀成日期，請自己幫它加上引號：*"may" 活動報告*。
- 沒有對應到任何人的 @ 或 # 會以黃色外框顯示，並留在標題中。

## 在哪裡新增很重要

- 從 **我的任務** 新增，任務就是你的。
- 在 **看板** 上，任務會進入看板的第一欄；可在視窗底部變更看板和欄位。
- 在 **客戶頁面** 上，任務會連結到該客戶。
- 在 **日曆** 上，點某一天的 **+** 會把任務放在那一天。

## 一次新增多個任務

貼上幾行文字（例如會議記錄）：每一行都會成為一個獨立的任務，新增之前會全部列出來。按 **Ctrl Enter**（Mac 為 **⌘ Enter**）全部新增。勾選「繼續新增」時，視窗會保持開啟。

## 一鍵完成

在清單和卡片上，每個任務前面都有一個圓形勾選：點一下，任務就會移到看板的「完成」欄。點錯了？在出現的通知中點 **復原**。任務視窗中的 **標示為完成** 按鈕也有同樣效果。

## 鍵盤快速鍵

除了在輸入框中打字時，快速鍵在任何地方都能用。按 **?** 也能在 App 內看到這份清單。

| 按鍵 | 作用 |
| --- | --- |
| N | 新任務 |
| Ctrl K 或 / | 搜尋並前往 |
| ? | 鍵盤快速鍵 |
| Esc | 關閉目前開啟的項目 |
| 先 G 再 H | 首頁 |
| 先 G 再 M | 我的任務 |
| 先 G 再 C | 日曆 |
| 先 G 再 A | 客戶 |
| 先 G 再 P | 個人資料與通知 |
| 先 G 再 S | 設定 |

## 在手機上

底部有五個按鈕：首頁、我的任務、中間的 **+**、客戶和日曆。看板、設定和你的選單在左上角的 ☰ 裡。

## 外觀

在你的選單（左下角你的名字）中選擇 **淺色**、**深色** 或 **與此裝置相同**。選擇會保存在這台裝置上。
