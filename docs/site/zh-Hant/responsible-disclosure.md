# 回報安全問題

如果你認為發現了 Curahold 的安全問題，請先告訴我們，並在告訴其他人之前給我們修正的時間。我們感謝每一份謹慎的回報。

## 如何回報

寄到 [/.well-known/security.txt](/.well-known/security.txt) 中的地址（**Contact** 那一行）。請寫明你發現了什麼、問題出現在哪個網址或畫面、重現的步驟，以及別人能拿它做什麼。截圖或短片會很有幫助。請用英文或土耳其文書寫。

請不要把細節公開在公開場合、求助請求或社群網路上。

## 我們的承諾

- 在三個工作天內確認收到你的回報。
- 在十個工作天內告訴你我們的看法和計畫。
- 在修正之前持續告知你進度，修正後也會通知你。
- 如果你願意，我們會在說明修正時提到你的名字。
- 對於善意且遵守這些規則的研究，我們不會採取法律行動。

## 測試規則

- 只使用你自己建立的帳號，或為測試而設立的公司。絕對不要讀取、變更或刪除其他公司或個人的資料；如果不小心接觸到了，請停下來，不要保留任何東西，並告訴我們。
- 不要讓服務對其他人變慢：不做負載或阻斷服務測試，不做比人工點擊更快的自動掃描。
- 不對我們的員工或客戶進行社交工程，也不做實體測試。
- 自行架設的安裝屬於運作它的公司；程式碼的問題請回報給我們，設定的問題請回報給該公司。

## 不在範圍內

沒有實際可行攻擊的「最佳實務」標頭缺漏回報、對每個地址都顯示相同內容的電子郵件連結登入頁面（刻意如此）、手動也能觸發的速率限制，以及需要裝置已經落入攻擊者手中的問題。
