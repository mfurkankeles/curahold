# 客戶入口

客戶入口會把選定的看板開放給客戶公司的人員。他們在自己的網址登入（例如 `acme.curahold-portal.com`），查看自己公司有哪些事項正在處理、進度如何，提出新請求並回覆。

## 客戶看得到什麼，永遠看不到什麼

| 看得到 | 永遠看不到 |
|---|---|
| 自己公司 **與他們共用** 的任務 | 其他客戶的任何任務 |
| 標題、說明、狀態（以你為該欄設定的名稱顯示） | 內部備註和內部留言 |
| 以 **回覆客戶** 寫的留言 | 你的團隊、角色和其他人員 |
| 你在看板上允許的詳細資料（截止日期、優先順序、負責人） | 客戶欄位、交易、健康評分、記錄 |
| | 其他看板、其他公司，以及 Curahold 本身 |

入口在獨立的網域上運作：從入口完全無法接觸到 App 的工作階段、Cookie 和 API。入口請求背後的資料庫角色不能讀取任何資料表；它只能呼叫入口函式，而這些函式只會回傳已登入者所屬公司的資料。

## 開啟（管理員）

1. **「設定」→ 客戶入口 → 客戶入口網站已開啟。** 客戶登入的網址會顯示在這裡。
2. 在要開放的 **看板設定** → **客戶入口** 中：
   - **將此看板開放給客戶**
   - **新請求會進入：** 選擇一欄。新請求會指派給該客戶的負責人。
   - **客戶看到的各欄位名稱：** 例如用「審核中」取代「等待法務」。留空則顯示欄位本身的名稱。
   - **客戶可看到的詳細資料：** 截止日期、優先順序、負責人。

私人看板不能開放。關閉開關會立刻對所有人關閉入口。

## 邀請人員

在 **「設定」→ 客戶入口 → 可登入的人員** 中，或在客戶頁面的 **客戶入口** 區塊：填寫姓名和電子郵件，然後點 **邀請**。客戶的負責人和管理員可以邀請。

- 邀請只能用一次，有效期 7 天。之後，人員可用公司允許的任何方式登入（見下文）。
- 不能邀請你們公司內部人員的地址；入口是給客戶用的。
- **停用** 會立刻終止他們的存取權和已開啟的工作階段。

## 登入方式

在 **「設定」→ 客戶入口 → 客戶的登入方式** 中，選擇適合你們客戶的方式：

| 方式 | 運作方式 |
|---|---|
| **電子郵件驗證碼與連結** | 一封附有六位數驗證碼和連結的郵件，各自只能用一次，30 分鐘內有效。有了驗證碼，就能在手機上看信、在電腦上登入。 |
| **Google** | 對方公司的 Google 帳號。如果對方公司關閉了帳號，入口也會對他們關閉。 |
| **Microsoft** | 對方的 Microsoft 365 帳號。第一次用 Microsoft 登入時，會用寄出的驗證碼確認一次；之後就會直接辨識帳號。 |
| **密碼金鑰** | 指紋、臉部或裝置 PIN 碼。最安全的方式；第一次登入後可在 **你的帳號** 中加入。密碼金鑰只在該入口的網址上有效，絕不會在仿冒網站上運作。 |
| **密碼** | 給有需要的客戶使用（預設關閉）。至少 10 個字元；連續輸錯五次會鎖定 15 分鐘；「忘記密碼？」可透過電子郵件重設。 |

- **保持登入：** 1、7、30（預設）或 90 天。
- **登入通知：** 用 Google、Microsoft、密碼金鑰或密碼登入後，對方會收到一封「新登入」電子郵件（可以關閉）。
- 關閉某種方式會結束用該方式開啟的工作階段；縮短保持登入的時間會結束較早的工作階段。至少要保留一種登入方式（電子郵件、Google、Microsoft 或密碼）。
- 登入表單絕不會透露某個地址是否有存取權，同一個地址每小時最多收到 5 封郵件。
- 在 **你的帳號** 中，人員可以加入密碼金鑰、設定密碼、解除 Google/Microsoft 連結，或從所有裝置登出。

## 共用任務與回覆

- 客戶提出的請求會自動共用。
- 要顯示你們團隊建立的任務，在任務面板中勾選 **與客戶共用**（任務需要連結客戶，並位於已開放的看板上）。
- 在共用任務上留言時，選擇 **內部備註**（預設）或 **回覆客戶**。回覆客戶的內容會以橘色線條和「客戶可見」標示，並以電子郵件寄給客戶。
- 客戶寫的內容會帶有「客戶」標籤，並以通知送給任務的負責人。
- 任務連結的客戶變更時，共用會自動關閉：一個客戶的對話絕不會轉到另一個客戶那裡。

## 客戶傳送的檔案

客戶只能向與其共享的請求和工單，以及其入門計畫的步驟傳送檔案。其他地方都不行。

- 支援文件、圖片、試算表、CSV、PDF 和 ZIP，每個最大 25 MB。每個檔案都會依類型和開頭位元組檢查，並且一律以下載方式開啟。
- 客戶總共能傳送多少，在設定 → **客戶入口** → **客戶傳送的檔案**中設定（預設 2,048 MB）。用滿後，客戶會被告知改用其他方式傳送。
- 客戶傳送的每個檔案都會顯示在該客戶的時間軸上。

## 限制

每人每天最多可提出 30 個請求、寫 200 則回覆。
