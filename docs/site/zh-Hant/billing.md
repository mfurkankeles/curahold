# 方案與帳單

## 免費試用

新公司可以免費使用所有功能 **14 天**，不需要信用卡。「設定」→ **帳單** 會顯示還剩幾天；最後一週，App 頂端也會有一行提示。

## 方案

| | Team | Business |
| --- | --- | --- |
| 看板、任務、清單和自動化 | ✓ | ✓ |
| 客戶、聯絡人、商機和你們自己的記錄 | ✓ | ✓ |
| 會議、時間軸、健康評分和業務檢視 | ✓ | ✓ |
| 報表、儀表板和目標 | ✓ | ✓ |
| Slack、Teams、Google Chat 和電子郵件通知 | ✓ | ✓ |
| 與 CRM 或試算表雙向同步 | | ✓ |
| 客戶入口 | | ✓ |
| 行動手冊，以及自動開始的續約 | | ✓ |

價格以每個 **完整席次** 每月計算，以美元計價，年繳更便宜；結帳時另加稅金。**檢視者席次免費。**

## 選擇方案

管理員開啟「設定」→ **帳單**，選擇月繳或年繳，然後按 **選擇Team** 或 **選擇Business**。付款頁面（由我們的經銷商 Paddle 提供）會在 App 上方開啟；完成後，幾秒內方案就會顯示在頁面上。

## 席次

帳單依以完整席次 **加入** 的人員計算：尚未接受的邀請不計費。新增一個人，多出的席次依本期剩餘時間計費；移除一個人，下一期帳單就會降低。沒有人需要手動修改席次數。

## 發票、付款方式、取消

帳單頁面上的 **發票、付款與取消** 會開啟 Paddle 的客戶入口，而且已經登入：下載發票、更換信用卡、取消。取消的方案會持續運作到已付款期間結束。

在 Team 與 Business 之間、或月繳與年繳之間切換，也在同一頁完成；差額會依本期剩餘時間計費（或退還）。

## 沒有方案時

試用結束卻沒有選擇方案，或已取消的方案到期時，不會刪除任何東西。所有人仍然可以 **閱讀和匯出** 全部內容；在管理員選擇方案之前不能做任何變更，選好之後，工作會從停下的地方繼續。

如果付款失敗，在 Paddle 重試期間一切照常運作；頂端的提示會請管理員更新付款方式。

## 你們自己的伺服器

安裝在你們自己伺服器上的 Curahold 沒有帳單：所有功能都開放。
