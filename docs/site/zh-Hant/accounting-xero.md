# Xero（會計）

來自 Xero 的客戶、銷售發票和收款。

## 讀取哪些內容

客戶（以及軟體中儲存的統一編號、電子郵件和網址）、含到期日和未付金額的發票，以及收到的款項。Curahold 絕不會寫入 Xero：它無法在那裡建立、變更或刪除任何內容。

## 連接

在**設定 → 資料來源**中找到**會計軟體**，選擇**連接 Xero**。然後：

1. 登入 Xero 並選擇要連接的組織。
2. 允許讀取聯絡人和交易；Curahold 無法變更 Xero 中的任何內容。
3. 回到這裡後，開始首次讀取，並檢查未能配對的客戶。

## 限制與時間

Xero 允許每個組織每分鐘 60 次呼叫並設每日額度（Xero 免費開發者層級為 1,000 次）。Curahold 控制速度，始終低於這兩個限制；達到當天額度時會在下一次執行時繼續。每小時讀取一次變更。

## 發生問題時

如果 Xero 不再接受連接（金鑰或登入被撤銷），該連接會在 設定 → 連接 中標示為「有問題」，並通知管理員一次；在其頁面上選擇**重新連接**。速率限制的回覆不是錯誤：本次執行會停下、記住位置，下次繼續。
