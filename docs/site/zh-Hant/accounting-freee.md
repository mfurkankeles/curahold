# freee（會計）

來自 freee 會計的往來對象（取引先）和銷售交易。

## 讀取哪些內容

客戶（以及軟體中儲存的統一編號、電子郵件和網址）、含到期日和未付金額的發票，以及收到的款項。Curahold 絕不會寫入 freee：它無法在那裡建立、變更或刪除任何內容。

## 連接

在**設定 → 資料來源**中找到**會計軟體**，選擇**連接 freee**。然後：

1. 登入 freee 並選擇要連接的事業所。
2. 允許存取；Curahold 只讀取往來對象和銷售交易。
3. 回到這裡後，開始首次讀取，並檢查未能配對的客戶。

## 限制與時間

Curahold 維持每秒少於一次請求。往來對象每次完整讀取（freee 不提供「自某時起變更」篩選）；在上次執行當天或之後變更的交易會重新讀取。金額以日圓計。

## 發生問題時

如果 freee 不再接受連接（金鑰或登入被撤銷），該連接會在 設定 → 連接 中標示為「有問題」，並通知管理員一次；在其頁面上選擇**重新連接**。速率限制的回覆不是錯誤：本次執行會停下、記住位置，下次繼續。
