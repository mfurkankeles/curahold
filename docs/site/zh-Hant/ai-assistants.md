# 連接 Claude 與 ChatGPT

把 Curahold 連接到 Claude、ChatGPT 或任何支援 MCP 的助理，助理就能以你的身分在 Curahold 中查資料、完成工作。

## 可以問什麼

- 「我的客戶中，哪些會在未來 60 天內續約而且看起來有風險？」
- 「整理一下港線銀行的關係人和未完成的工作。」
- 「把我的客戶組合做成一份 5 頁的摘要。」
- 「幫陳雅婷開一個明天到期的任務，調查維途交通的使用量下滑。」
- 「把這個任務標示為完成，並留言『提案已寄出』。」

## 如何連接

1. 在 Curahold 中開啟 **你的設定**，複製 **連接器位址**。它看起來像 `https://yourcompany.curahold.com/mcp`。
2. **Claude：** Settings → Connectors → Add custom connector。貼上位址並連接。
   **ChatGPT：** 在連接器設定中，用這個位址新增一個自訂（MCP）連接器。部分方案需要先開啟開發人員模式。
3. Curahold 的授權畫面會開啟。登入、確認助理可以做什麼，然後選擇 **允許**。

## 安全

- 助理以 **你的身分** 工作。它只看得到你看得到的，只能變更你能變更的。你的角色和欄位規則照常適用。
- 在授權畫面上取消勾選「同時允許變更」，助理就只能讀取。在檢視者席次上，它本來就只能讀取。
- 隨時都能在「你的設定」→ API 金鑰與已連接的應用程式 中中斷連線。
- 助理使用你自己的 Claude 或 ChatGPT 方案；Curahold 不會為 AI 額外收費。
