# 可接受使用政策

> **草稿——須經律師核准。** 版本 2026-11-19.draft2。服務條款的一部分。本文為英文版本的譯本，僅供閱讀便利；如有任何不一致，以英文版本為準。

客戶及其使用者不得使用 Curahold：

1. 違反法律或侵害他人權利，或儲存、傳送違法、侵權、誹謗或騷擾性內容；
2. 未經收件人許可傳送垃圾訊息或行銷訊息；
3. 上傳惡意軟體，或對服務進行探測、掃描、負載測試或攻擊，或試圖存取其他公司的資料或不屬於自己的帳號（安全研究僅限依「回報安全問題」頁面進行）；
4. 多人共用一個席位、規避裝置上限、席位數或其他限制，或未經書面協議轉售或再授權服務；
5. 複製或重製服務、其設計或內容，或對其進行還原工程、反編譯或反組譯（強制性法律允許者除外）；
6. 未經我們書面許可，以自動化方式擷取、爬取或以其他方式存取服務、其頁面或說明文件——允許使用客戶自己的金鑰在限制內透過已公布的 API 存取；
7. 使用 AI 代理、機器人或瀏覽器自動化探索、記錄或擷取服務的功能、畫面、工作流程、內容或設計；
8. 建構或改進競爭產品，或為此目的對服務進行效能比較或測試；
9. 對服務、說明文件或我們的網站進行文字與資料探勘（權利保留——條款第 9 條）；
10. 儲存**特種個人資料**（健康、生物特徵、宗教、犯罪紀錄等）、付款卡號或**兒童資料**，以書面約定者除外；
11. 在受全面制裁的國家使用服務或為其中的人員使用服務，或為制裁名單上的任何人使用服務；
12. 祕密監控員工，或以法律禁止的方式使用活動功能——客戶須事先告知員工，並將個人層級的檢視限於有需要的角色；
13. 使用 AI 功能產生違法內容、在沒有人為決定的情況下對個人作出具法律效果的決定，或以違反模型提供者使用規則的方式使用。

**合理使用。**API、自動化、匯入、匯出與 AI 功能設有限制，讓服務對所有人都保持快速（載於 API 參考文件並在產品中顯示）。遠超正常使用的流量可能會被降速，或被要求改用合適的方案。超過限制的請求會收到「請求過多」的回應及等待時間；已知的爬蟲與自動化工具可能會被直接拒絕。

**後果。**我們會盡可能先發出警告並要求改正。違規嚴重或持續時，我們得刪除內容、於最小必要範圍內降速或**停權**；對嚴重或反覆的違規，得**終止**協議（條款第 13 條）。請將濫用情形回報至 [濫用回報電子郵件]。
