# 安全與隱私

## 公司之間看不到彼此

每個查詢都在資料庫的列層級安全規則下執行。任何方式都無法從另一家公司的網址、API 或連接器讀取某家公司的資料。角色和欄位規則也在同一層強制執行。

## 工作階段與裝置

工作階段綁定在裝置上；複製的 Cookie 在另一台機器上無法使用。超過裝置數量限制時，最早的工作階段會被登出。在「你的設定」→ 裝置 中查看並結束你的工作階段。

## 密碼金鑰與第二步驗證

除了電子郵件連結，你還能用 **密碼金鑰**（指紋、臉部或裝置 PIN 碼）登入，並加入 **第二步驗證**：一個驗證器 App，以及十組手機遺失時使用的一次性復原碼。在 **我的裝置 → 登入安全** 中設定，也能在那裡一次登出所有其他裝置。管理員可以在 **「設定」→ 登入** 中要求管理員或所有人使用第二步驗證；每次登入時都會在伺服器上檢查。透過單一登入登入的人不會再被詢問：由身分識別提供者負責。不會有人被鎖在門外：管理員可以重設某人的第二步驗證，自行架設的安裝則可在伺服器環境中重設（`RESET_SECOND_STEP`）。

當你的登入已超過十分鐘時，變更角色、單一登入或 SCIM、建立 API 金鑰、匯出或清除個人資料、移除人員，以及匯出活動紀錄，都會要求你確認是本人（密碼金鑰、App 驗證碼或寄出的驗證碼）。

## 保存在裝置上的內容

為了讓你在沒有網路時也能閱讀，App 會把你最後看過的清單副本保存在瀏覽器自己的儲存空間中（任務、看板、客戶、收件匣；不含附件和設定）。副本只留在這台裝置和這個瀏覽器中，不會傳送到任何地方。登出時，或在伺服器上結束工作階段後第一次連線時，副本會被刪除。在共用電腦上，用完請登出。

## 活動紀錄

登入、第二步驗證、人員與角色的變更、連線、API 金鑰、webhook 以及個人資料操作都會寫入活動紀錄，見設定 → 活動紀錄。紀錄永遠不會被變更，即使應用程式使用的資料庫角色也無法刪除；12 個月後由夜間清理移除（資料庫會拒絕刪除任何不滿 90 天的紀錄）。**匯出紀錄**會附帶連續的 SHA-256 指紋下載；最終指紋也會寫入紀錄，以便日後核對副本。

## 客戶入口

客戶入口在獨立的網域上運作，有自己的工作階段和 Cookie。入口請求背後的資料庫角色對任何資料表都沒有權限；它只能呼叫回傳已登入者所屬公司共用資料的函式。詳情：[客戶入口](/docs/zh-Hant/customer-portal/)。

## Curahold 支援人員的存取

Curahold 支援人員只有在某人同意時才會進入公司：此人在求助請求中勾選選項，並選擇期限（24 小時到 7 天）。支援人員看到的就是此人看到的，而且只能查看：永遠不能變更任何東西。所選的期限一到存取就會結束，也能隨時關閉。每一次造訪，以及支援人員在期間讀取的內容，都會連同支援人員的姓名寫入活動紀錄。管理員可以在 **「設定」→ 安全 → 支援存取** 中將其限制為僅限管理員，或將其關閉。詳情：[取得協助](/docs/zh-Hant/getting-help/)。

## 個人資料

在「設定」→ 人員 中，每個人的選單提供：

- **下載個人資料：** 與此人有關的一切，整理成一個檔案。
- **清除個人資料：** 刪除姓名和電子郵件；此人完成的工作會以匿名方式保留。請先把此人的客戶和未完成任務交給別人。
- **清除**也會移除此人向 CuraAI 提出的問題、通知、聊天連結、通行金鑰與第二步驗證、工作階段錄影，以及 AI 團隊筆記中提到其地址或全名之處。法律要求保留的會保留：發票、代表公司接受條款的紀錄，以及不含地址（只保留其指紋）的同意紀錄。
- **你的客戶那邊的人員**（設定 → 客戶入口網站 → 可登入的人員）：負責隱私的管理員可以**下載資料**或**清除個人資料**。清除會刪除入口網站帳號本身；其寫下的內容會保留，但不顯示姓名。

### 刪除整個公司

管理員可以在**設定 → 公司 → 刪除公司**輸入公司網址提出申請。30 天內不會刪除任何內容：公司照常運作，你仍可匯出，任何管理員都可以取消。之後所有內容（包括檔案與連線金鑰）都會永久刪除，並保留一份列出刪除內容的刪除證明（不含姓名或地址）。發票會依稅法規定保留。備份依託管服務供應商的週期輪替刪除。

## 資料保留期間

| 資料 | 保留期間 |
| --- | --- |
| 通知 | 90 天 |
| 已結束的工作階段 | 90 天 |
| 同步歷史 | 90 天 |
| [垃圾桶](/docs/zh-Hant/trash/) 中已刪除的客戶、記錄、任務等 | 30 天，之後連同檔案清除；管理員可以提早清除 |
| 匯入的復原資料 | 30 天 |
| webhook 傳送紀錄 | 7 天 |
| 錯誤紀錄（哪裡出了什麼問題——絕不含請求內容） | 30 天 |
| 已撤銷的 API 金鑰 | 30 天 |
| 活動紀錄 | 12 個月 |
| 協助請求及其訊息與檔案 | 最後一次變更後 24 個月 |
| 向 CuraAI 提出的問題 | 依你的公司選擇（未變更則為 30 天） |
| 已刪除的公司 | 申請 30 天後清除 |

## 儲存的機密

CRM 和聊天連線的憑證，以及 webhook 簽章密鑰，都以加密方式儲存。API 金鑰只保留摘要：金鑰本身只顯示一次，之後再也看不到。
