# 時間軸與健康評分

每個客戶頁面都有 **時間軸**，如果你開啟了，還會有 **健康評分**。時間軸說明和客戶之間發生了什麼；評分則把這些濃縮成一個數字，並附上原因。

## 時間軸

在頂端的輸入框中選擇 **備註**、**通話**、**會議** 或 **電子郵件**，寫下發生的事並新增。需要的話可以修改日期，並勾選你交談過的人。

以下內容會自動出現在時間軸上：

- 為該客戶建立和完成的任務
- 這些任務上的留言
- 新增的聯絡人（關係人）
- 健康評分變動 10 分以上的日子

把重要的備註 **置頂**，它就會一直留在最上方。條目的作者或負責管理客戶的人可以編輯或刪除它。你無法開啟的看板上的任務，或對你隱藏的欄位，也不會出現在時間軸上。

## 已安排的會議

時間軸記錄的是已經發生的事。**已安排的會議** 是還沒發生的事。在客戶頁面的 **即將舉行的會議** 底下選擇 **安排會議**：選擇類型（會議、檢視或通話，或你儲存的某個類型），設定開始時間和時長，邀請雙方人員，寫好議程，並選擇是否重複。會議會顯示在客戶頁面和你的 **日曆** 上，但還不會出現在時間軸上——會議舉行之前不會記錄任何東西。

每場已安排的會議都有自己的流程：

- 會議舉行後點 **標示為已舉行**。這會把會議記錄到時間軸上，議程當作備註，並把兩者連結起來。如果是重複會議，下一場會自動安排好。你可以順便約定後續步驟，每一步都會成為一個任務。
- 填寫原因後 **延期**。會議會保留，你可以把它改到另一天的同一時間。
- 填寫原因後 **取消**。它會以「已取消」留在記錄中——不會刪除任何東西。

**儲存的類型。** 管理員可以替你們常開的會議命名（例如季度業務檢視、每月例行會議），並為每一種設定議程提示。安排時選擇類型就會填好議程，讓每次檢視都從同樣的問題開始。

## 健康評分

在「設定」→ 健康評分 中開啟。它是每個客戶 0 到 100 之間的一個數字，依 Curahold 中已有的資訊計算：

| 訊號 | 滿分 | 零分 |
| --- | --- | --- |
| 最近接觸 | 最近一次通話、會議、電子郵件或備註在 14 天內 | 45 天以上 |
| 逾期工作 | 沒有逾期任務 | 3 個以上逾期任務 |
| 支援負擔 | 沒有未結的支援工單 | 5 張未結工單（緊急工單算兩張） |
| 核心支持者 | 至少一位「核心支持者」聯絡人 | 沒有 |
| 已知決策者 | 至少一位「決策者」聯絡人 | 沒有 |
| 沒有阻礙者 | 沒有阻礙者或懷疑者 | 有阻礙者 |
| 負責人的判斷 | 某個選項欄位的第一個選項（例如「良好」） | 最後一個選項（例如「有風險」） |
| 數字欄位 | 你設定的值 | 你設定的值 |

權重、天數和區間（健康、需留意、有風險）都由你決定。儲存之前，預覽會顯示每個客戶的分數。某個客戶沒有資料的訊號會被略過，由其他訊號分攤它的權重。

> **為什麼？** 在客戶頁面的評分旁，**為什麼？** 會顯示每個訊號給了幾分，以及最近幾週的圖表。評分不是黑盒子：每一分的來源都看得見。

評分和任何客戶欄位一樣使用：清單中的一欄、篩選條件、首頁卡片、匯出、API 和 webhook。在 CRM 同步中把它對應到某個欄位，它也會寫進你的 CRM。任何人都不能手動輸入。

客戶有任何變動後幾秒內會重新計算，每天也會計算一次。每天的評分都會保留；趨勢和每週摘要就是從這裡來的。

## 每週摘要

每週一，在你為晨間摘要選擇的時間，你會收到一份客戶摘要：未來 30 天內的續約、下滑的評分與主要原因、30 天以上沒有接觸的客戶，以及本週的工作。可以在「你的設定」中關閉。
