# حسابداری: فایل از هر برنامهٔ دیگر

برنامه‌هایی که API باز ندارند — Logo، Mikro، Tally، SAP Business One و بقیه — با فایل وصل می‌شوند. ارقام سپس درست مثل یک برنامهٔ متصل کار می‌کنند: صفحهٔ مشتری، تطبیق و امتیاز سلامت.

## مراحل

1. در **تنظیمات ← منابع داده ← برنامه‌های حسابداری**، **بارگذاری فایل** را انتخاب کنید.
2. در زبانهٔ **بارگذاری**، **الگو** را برای مشتریان، فاکتورها و پرداخت‌ها دانلود کنید.
3. همین‌ها را از برنامهٔ خود خروجی بگیرید و در ستون‌های الگو بگذارید (Excel یا CSV؛ ستون‌های اضافی نادیده گرفته می‌شوند).
4. اول مشتریان، بعد فاکتورها و سپس پرداخت‌ها را بارگذاری کنید.

## ستون‌ها

| فایل | ستون‌ها |
| --- | --- |
| مشتریان | customer_id, name, tax_id, email, website, currency, balance |
| فاکتورها | invoice_id, customer_id, number, issued_on, due_on, currency, total, balance, status |
| پرداخت‌ها | payment_id, customer_id, invoice_id, paid_on, amount, currency |

تاریخ‌ها به‌صورت YYYY-MM-DD. `status` می‌تواند open، paid، void یا draft باشد؛ اگر خالی بماند، فاکتوری که مانده دارد باز حساب می‌شود.

## ارقام تازه‌تر

هر وقت خواستید فایل جدیدی بارگذاری کنید: جای فایل قبلی از همان نوع را می‌گیرد. تطبیق‌های دستی حفظ می‌شوند. فایل به هیچ جای دیگری فرستاده نمی‌شود.
