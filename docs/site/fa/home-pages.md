# صفحه‌های خانه و کارت‌ها

صفحهٔ خانه برای این است که هر کس به محض باز کردن Curahold کارش را ببیند. هر صفحه از کارت‌ها ساخته شده و هر نقش با صفحهٔ خانهٔ خودش شروع می‌کند.

## کارت‌ها

| کارت | چه نشان می‌دهد |
| --- | --- |
| وظایف باز من | وظایف تمام‌نشدهٔ تو، اول عقب‌افتاده‌ها |
| تمدیدهای پیش رو | مشتری‌هایی که در بازهٔ روزهای انتخابی‌ات تمدید می‌شوند و ارزش کلشان |
| نیازمند توجه | مشتری‌هایی که سلامتشان در خطر یا نیازمند مراقبت است |
| بی‌خبر مانده‌ها | مشتری‌هایی که مدتی هیچ فعالیتی نداشته‌اند |
| ریسک‌های ذی‌نفعان | مانع‌ها و مرددها، و مشتری‌هایی که حامی اصلی ندارند |
| یک عدد | یک مقدار تنها، مثل تعداد مشتری‌ها یا ارزش کل |
| تفکیک | مشتری‌ها تقسیم‌شده بر اساس یک فیلد گزینه‌ای |
| بار کاری تیم | مشتری‌ها و کارهای باز، عقب‌افتاده و در خطرِ هر نفر |
| اتصالات | وضعیت همگام‌سازی با CRM و صفحه‌گسترده‌ها |
| یادداشت | اعلان یا لینک کوتاه برای تیم |

بیشتر کارت‌ها برای «مال من»، «مال تیمم» یا «مال همه» کار می‌کنند. هر کارت در محدودهٔ چیزهایی حساب می‌شود که بیننده اجازهٔ دیدنشان را دارد: دو نفر که یک صفحه را باز می‌کنند، اگر دسترسی‌شان فرق کند عددهای متفاوتی می‌بینند.

## ویرایش صفحه

مدیران با **ویرایش صفحه** کارت اضافه می‌کنند، ترتیب و اندازه‌شان را تعیین می‌کنند و انتخاب می‌کنند کدام نقش‌ها با این صفحه شروع کنند. یک صفحه را می‌توان فقط به بعضی نقش‌ها هم نشان داد.

> **نکته:** برای این‌که ببینی یک نقش چه می‌بیند، در «تنظیمات» ← نقش‌ها و دسترسی‌ها از **مشاهده به‌عنوان …** استفاده کن. صفحه‌های آن فرد را فقط‌خواندنی باز می‌کند.
