# Paraşüt (הנהלת חשבונות)

לקוחות, חשבוניות מכירה ותשלומים מ-Paraşüt.

## מה נקרא

לקוחות (עם מספר עוסק, דוא״ל וכתובת אתר כשהתוכנה שומרת אותם), חשבוניות עם מועד התשלום והסכום שנותר, ותשלומים שהתקבלו. ‏Curahold לא כותב דבר ל-Paraşüt: הוא לא יכול ליצור, לשנות או למחוק שם שום דבר.

## חיבור

ב**הגדרות ← מקורות נתונים**, מצאו את **תוכנות הנהלת חשבונות** ובחרו **חיבור Paraşüt**. אחר כך:

1. בקשו מהתמיכה של Paraşüt גישת API לחברה שלכם; הם ישלחו client ID ו-client secret.
2. מספר החברה מופיע בשורת הכתובת אחרי uygulama.parasut.com/.
3. הזינו אותם עם הדוא״ל והסיסמה של משתמש Paraşüt. הסיסמה משמשת פעם אחת לקבלת מפתח ואינה נשמרת.

## מגבלות ותזמון

‏Paraşüt מאפשרת כ-10 בקשות בכל 10 שניות ומחזירה 25 שורות בעמוד; אין לה מסנן "השתנה מאז", ולכן כל הרצה קוראת את הרשימות במלואן. לעסק קטן אלה כמה עשרות עמודים. הסכומים נקראים במטבע החשבונית (TRY, ‏USD, ‏EUR, ‏GBP).

## אם משהו משתבש

אם Paraşüt מפסיקה לקבל את החיבור (מפתח או התחברות שבוטלו), החיבור מסומן "בעיה" בהגדרות ← חיבורים והמנהלים מקבלים הודעה אחת; בחרו **חיבור מחדש** בדף שלו. תשובת מגבלת קצב אינה שגיאה: ההרצה נעצרת, שומרת את מקומה וממשיכה בפעם הבאה.
