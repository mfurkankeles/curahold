# עמודי בית וכרטיסים

עמוד הבית קיים כדי שאנשים יראו את העבודה שלהם ברגע שהם פותחים את Curahold. כל עמוד בנוי מכרטיסים, וכל תפקיד מתחיל בעמוד בית משלו.

## כרטיסים

| כרטיס | מה הוא מציג |
| --- | --- |
| המשימות הפתוחות שלי | המשימות שלכם שלא הושלמו, אלה שבאיחור קודם |
| חידושים קרובים | לקוחות שמתחדשים בתוך מספר הימים שתבחרו, והשווי הכולל שלהם |
| דורשים תשומת לב | לקוחות שהבריאות שלהם בסיכון או שווה מעקב |
| נעלמו | לקוחות בלי פעילות כבר זמן מה |
| סיכוני בעלי עניין | חוסמים וספקנים, ולקוחות בלי תומך מרכזי |
| מספר | ערך יחיד, כמו מספר הלקוחות או השווי הכולל |
| פילוח | לקוחות מחולקים לפי שדה בחירה |
| עומס הצוות | לקוחות, עבודה פתוחה, באיחור ובסיכון לכל אדם |
| חיבורים | מצב הסנכרון עם CRM וגיליונות |
| הערה | הודעה קצרה או קישור לצוות |

רוב הכרטיסים עובדים עבור "שלי", "של הצוות שלי" או "של כולם". כרטיס מחושב בתוך מה שהצופה רשאי לראות: שני אנשים שפותחים את אותו עמוד רואים מספרים שונים אם ההרשאות שלהם שונות.

## עריכת עמוד

מנהלים משתמשים ב**ערוך עמוד** כדי להוסיף כרטיסים, לסדר אותם ולשנות את גודלם, ולבחור אילו תפקידים מתחילים בעמוד הזה. אפשר גם להציג עמוד רק לחלק מהתפקידים.

> **טיפ:** כדי לבדוק מה תפקיד מסוים רואה, השתמשו ב**הצג כפי ש… רואה** ב'הגדרות' ← תפקידים והרשאות. זה פותח את המסכים של אותו אדם, לקריאה בלבד.
