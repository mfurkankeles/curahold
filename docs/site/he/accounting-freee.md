# freee (הנהלת חשבונות)

שותפים (取引先) ועסקאות מכירה מ-freee Accounting.

## מה נקרא

לקוחות (עם מספר עוסק, אימייל וכתובת אתר כשהתוכנה שומרת אותם), חשבוניות עם מועד התשלום והסכום שנותר, ותשלומים שהתקבלו. ‏Curahold לא כותב דבר ל-freee: הוא לא יכול ליצור, לשנות או למחוק שם שום דבר.

## חיבור

ב**הגדרות ← מקורות נתונים**, מצאו את **תוכנות הנהלת חשבונות** ובחרו **חיבור freee**. אחר כך:

1. התחברו ל-freee ובחרו את החברה (事業所) לחיבור.
2. אשרו גישה; Curahold קורא רק שותפים ועסקאות מכירה.
3. כשתחזרו לכאן, התחילו את הקריאה הראשונה ובדקו את הלקוחות שלא הותאמו.

## מגבלות ותזמון

‏Curahold שומר על פחות מבקשה אחת בשנייה. שותפים נקראים במלואם בכל פעם (ב-freee אין להם מסנן "השתנה מאז"); עסקאות שהשתנו ביום ההרצה האחרונה או אחריו נקראות שוב. הסכומים ביין.

## אם משהו משתבש

אם freee מפסיקה לקבל את החיבור (מפתח או התחברות שבוטלו), החיבור מסומן "בעיה" בהגדרות ← חיבורים והמנהלים מקבלים הודעה אחת; בחרו **חיבור מחדש** בדף שלו. תשובת מגבלת קצב אינה שגיאה: ההרצה נעצרת, שומרת את מקומה וממשיכה בפעם הבאה.
