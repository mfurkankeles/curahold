# Odoo (הנהלת חשבונות)

לקוחות, חשבוניות ותשלומים מ-Odoo Online, ‏Odoo.sh או מהשרת שלכם.

## מה נקרא

לקוחות (עם מספר עוסק, אימייל וכתובת אתר כשהתוכנה שומרת אותם), חשבוניות עם מועד התשלום והסכום שנותר, ותשלומים שהתקבלו. ‏Curahold לא כותב דבר ל-Odoo: הוא לא יכול ליצור, לשנות או למחוק שם שום דבר.

## חיבור

ב**הגדרות ← מקורות נתונים**, מצאו את **תוכנות הנהלת חשבונות** ובחרו **חיבור Odoo**. אחר כך:

1. ב-Odoo, פתחו את הפרופיל ← העדפות ← אבטחת חשבון וצרו מפתח API.
2. רשמו את כתובת ה-Odoo ואת שם המשתמש. ב-Odoo.sh או בשרת משלכם, גם את שם מסד הנתונים.
3. הזינו אותם למטה. ב-Odoo Online, גישת API דורשת את תוכנית Custom (כלל של Odoo).

## מגבלות ותזמון

‏Odoo לא מפרסמת מגבלה קבועה; ‏Curahold שומר על כשתי בקשות בשנייה כדי לא להעמיס על שרת קטן. ‏Odoo 19 ואילך נקראות דרך JSON-2 API, וגרסאות ישנות דרך JSON-RPC (ואז צריך את שם מסד הנתונים). שינויים נקראים כל שעה.

## אם משהו משתבש

אם Odoo מפסיקה לקבל את החיבור (מפתח או התחברות שבוטלו), החיבור מסומן "בעיה" בהגדרות ← חיבורים והמנהלים מקבלים הודעה אחת; בחרו **חיבור מחדש** בדף שלו. תשובת מגבלת קצב אינה שגיאה: ההרצה נעצרת, שומרת את מקומה וממשיכה בפעם הבאה.
