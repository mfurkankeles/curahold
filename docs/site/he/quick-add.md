# הוספה מהירה וקיצורי דרך

לוחצים **N** (או **+ חדש ← משימה** בצד, **הוסף משימה** מתחת לעמודה, ה-**+** בתחתית המסך בטלפון) ונפתח החלון **משימה חדשה**. מתחת לכותרת הוא מבקש את הפרטים: תיאור, הלקוח, הרשומה שהמשימה שייכת אליה (הזדמנות, הסכם…), אחראים, תאריך יעד, עדיפות, חזרה, לוח ועמודה, ושדות הלוח. אם פתחתם אותו מעמודה, העמודה כבר בחורה; מעמוד לקוח – הלקוח.

לא חייבים למלא את השדות אחד אחד; מספיק לכתוב את הכותרת כמו שהיא עולה לכם בראש:

> שיחת חידוש friday @נועה #ולטו !high

השורה הזו ממלאת את השדות: נועה כאחראית, ולטו מוביליטי כלקוח, יעד ביום שישי, עדיפות גבוהה. שדה שמולא מהכותרת מציין **מהכותרת**. אם משנים שדה ידנית, המילים שלו יוצאות מהכותרת והשדה שומר את מה שבחרתם. **Enter** מוסיף את המשימה; מכל שדה אחר – **Ctrl Enter** (‏⌘ Enter ב-Mac).

## מה אפשר לכתוב

מילים של תאריך, חזרה ועדיפות כותבים באנגלית בכל השפות חוץ מטורקית.

| מה | איך | דוגמאות |
| --- | --- | --- |
| תאריך יעד | מילים יומיומיות | today, tomorrow, friday, next week, weekend, end of month, nov 15, 15.11, in 3 days |
| אדם | @ ושם | ‎@נועה, ‎@איתי לוי, ‎@me |
| לקוח | # והשם שלו | ‎#ולטו, ‎#בנק הארבורליין |
| עדיפות | ! ורמה | !urgent, !high, !low |
| חזרה | every … | every day, every week, every monday, every 2 weeks, monthly |

- הקלדת **@** או **#** פותחת רשימה; בוחרים עם מקשי החצים ו-**Enter** או **Tab**.
- ה-**×** על תווית: אדם, לקוח או עדיפות יוצאים מהשורה. מילים שנקראו כתאריך או כקצב נשארות בכותרת (במירכאות). אם מילה לעולם לא צריכה להיקרא כתאריך, שימו אותה במירכאות בעצמכם: *"may" דוח הקמפיין*.
- @ או # שלא מתאימים לאף אחד מוצגים עם מסגרת צהובה ונשארים בכותרת.

## המקום שבו אתם נמצאים משנה

- נוספה מ**המשימות שלי** – המשימה שלכם.
- ב**לוח** – היא נכנסת לעמודה הראשונה של הלוח; את הלוח והעמודה משנים בתחתית החלון.
- ב**עמוד לקוח** – היא מקושרת ללקוח הזה.
- ב**יומן** – ה-**+** ביום מסוים שם את המשימה ביום הזה.

## כמה משימות בבת אחת

מדביקים כמה שורות (למשל מסיכום פגישה): כל שורה הופכת למשימה משלה, וכולן מוצגות לפני שהן נוספות. **Ctrl Enter** (‏**⌘ Enter** ב-Mac) מוסיף את כולן. כשהאפשרות "המשך להוסיף" מסומנת, החלון נשאר פתוח.

## הושלם בלחיצה אחת

ברשימות ועל הכרטיסים, לפני כל משימה יש סימן וי עגול: לוחצים עליו והמשימה עוברת לעמודת "הושלם" של הלוח. טעות? **בטל** בהודעה שמופיעה. הכפתור **סמן כבוצע** בחלון המשימה עושה אותו דבר.

## קיצורי מקלדת

הם עובדים בכל מקום, חוץ מבזמן הקלדה בתיבה. **?** מציג את הרשימה הזו גם בתוך האפליקציה.

| מקש | מה הוא עושה |
| --- | --- |
| N | משימה חדשה |
| Ctrl K או / | חיפוש וניווט |
| ? | קיצורי מקלדת |
| Esc | סגור את מה שפתוח |
| G ואז H | בית |
| G ואז M | המשימות שלי |
| G ואז C | יומן |
| G ואז A | לקוחות |
| G ואז P | פרופיל והתראות |
| G ואז S | הגדרות |

## בטלפון

בתחתית יש חמישה כפתורים: בית, המשימות שלי, **+** באמצע, לקוחות ויומן. לוחות, הגדרות והתפריט שלכם נמצאים מאחורי ☰ בפינה העליונה.

## מראה

מהתפריט שלכם (השם שלכם בפינה התחתונה) בוחרים **בהיר**, **כהה** או **כמו במכשיר הזה**. הבחירה נשמרת במכשיר הזה.
