# הנהלת חשבונות: קובץ מכל תוכנה אחרת

תוכנות בלי API פתוח — Logo, ‏Mikro, ‏Tally, ‏SAP Business One ואחרות — מתחברות עם קובץ. הנתונים עובדים בדיוק כמו בתוכנה מחוברת: דף הלקוח, ההתאמה וציון הבריאות.

## שלבים

1. ב**הגדרות ← מקורות נתונים ← תוכנות הנהלת חשבונות**, בחרו **העלאת קובץ**.
2. בלשונית **העלאה**, הורידו את ה**תבנית** ללקוחות, חשבוניות ותשלומים.
3. ייצאו אותם מהתוכנה וסדרו בעמודות התבנית (Excel או CSV; עמודות נוספות לא נלקחות).
4. העלו קודם לקוחות, אחר כך חשבוניות ואז תשלומים.

## העמודות

| קובץ | עמודות |
| --- | --- |
| לקוחות | customer_id, name, tax_id, email, website, currency, balance |
| חשבוניות | invoice_id, customer_id, number, issued_on, due_on, currency, total, balance, status |
| תשלומים | payment_id, customer_id, invoice_id, paid_on, amount, currency |

תאריכים בפורמט YYYY-MM-DD. ‏`status` יכול להיות open, ‏paid, ‏void או draft; אם הוא ריק, חשבונית שנותר בה חוב נחשבת פתוחה.

## נתונים עדכניים יותר

העלו קובץ חדש מתי שתרצו: הוא מחליף את הקודם מאותו סוג. התאמות ידניות נשמרות. הקובץ לא נשלח לשום מקום אחר.
