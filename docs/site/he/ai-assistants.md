# חיבור Claude ו-ChatGPT

מחברים את Curahold ל-Claude, ל-ChatGPT או לכל עוזר שמדבר MCP, והעוזר יכול לחפש מידע ולבצע עבודה ב-Curahold בשמכם.

## מה אפשר לשאול

- "אילו מהלקוחות שלי מתחדשים ב-60 הימים הקרובים ונראים בסיכון?"
- "סכם את בעלי העניין והעבודה הפתוחה של בנק הארבורליין."
- "הכן סיכום של 5 שקפים על תיק הלקוחות שלי."
- "פתח משימה למאיה, עד מחר, לבדוק את הירידה בשימוש של ולטו מוביליטי."
- "סמן את המשימה הזו כבוצעה והוסף תגובה 'ההצעה נשלחה'."

## איך מתחברים

1. ב-Curahold פותחים את **ההגדרות שלך** ומעתיקים את **כתובת המחבר**. היא נראית כמו `https://yourcompany.curahold.com/mcp`.
2. **Claude:** ‏Settings ← Connectors ← Add custom connector. מדביקים את הכתובת ומתחברים.
   **ChatGPT:** מוסיפים בהגדרות המחברים מחבר מותאם (MCP) עם הכתובת הזו. בחלק מהתוכניות צריך קודם להפעיל את מצב המפתחים.
3. מסך ההרשאות של Curahold נפתח. נכנסים, בודקים מה העוזר רשאי לעשות ובוחרים **אפשר**.

## בטיחות

- העוזר עובד **בשמכם**. הוא רואה רק את מה שאתם יכולים לראות ומשנה רק את מה שאתם יכולים לשנות. כללי התפקיד והשדות שלכם חלים בלי שינוי.
- מבטלים את הסימון "אפשר גם שינויים" במסך ההרשאות והעוזר רק קורא. במושב צופה הוא ממילא רק קורא.
- מנתקים אותו בכל עת ב'ההגדרות שלך' ← מפתחות API ואפליקציות מחוברות.
- העוזר רץ על תוכנית ה-Claude או ה-ChatGPT שלכם; Curahold לא גובה שום תוספת על AI.
