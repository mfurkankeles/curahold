# अकाउंटिंग: किसी भी दूसरे सॉफ़्टवेयर की फ़ाइल

जिन सॉफ़्टवेयर में ओपन API नहीं है — Logo, Mikro, Tally, SAP Business One और बाकी — वे फ़ाइल से जुड़ते हैं। इसके बाद आंकड़े बिल्कुल कनेक्ट किए गए सॉफ़्टवेयर की तरह काम करते हैं: ग्राहक का पेज, मिलान और हेल्थ स्कोर।

## स्टेप

1. **सेटिंग → डेटा सोर्स → अकाउंटिंग सॉफ़्टवेयर** में **फ़ाइल अपलोड करें** चुनें।
2. **अपलोड** टैब पर ग्राहकों, इनवॉइस और भुगतानों का **टेम्पलेट** डाउनलोड करें।
3. अपने सॉफ़्टवेयर से यही डेटा एक्सपोर्ट करें और उसे टेम्पलेट के कॉलम में रखें (Excel या CSV; अतिरिक्त कॉलम छोड़ दिए जाते हैं)।
4. पहले ग्राहक, फिर इनवॉइस, फिर भुगतान अपलोड करें।

## कॉलम

| फ़ाइल | कॉलम |
| --- | --- |
| ग्राहक | customer_id, name, tax_id, email, website, currency, balance |
| इनवॉइस | invoice_id, customer_id, number, issued_on, due_on, currency, total, balance, status |
| भुगतान | payment_id, customer_id, invoice_id, paid_on, amount, currency |

तारीखें YYYY-MM-DD में। `status` में open, paid, void या draft हो सकता है (ödendi, açık, iptal… भी); खाली छोड़ने पर, जिस इनवॉइस पर अब भी रकम बाकी है उसे open माना जाता है।

## ताज़ा आंकड़े

जब चाहें नई फ़ाइल अपलोड करें: यह उसी तरह की पिछली फ़ाइल की जगह ले लेती है। आपके हाथ से किए गए मिलान बने रहते हैं। फ़ाइल कभी कहीं और नहीं भेजी जाती।
