# 역할과 권한

역할은 누가 무엇을 보고 바꿀 수 있는지 정합니다. 규칙은 인터페이스만이 아니라 데이터베이스에서 강제됩니다. 화면에서 숨긴 것은 API, 내보내기, AI 커넥터에서도 숨겨집니다.

## 좌석

- **전체 권한 좌석:** 보고 바꿀 수 있습니다.
- **뷰어 좌석:** 보기만 합니다. 관리자와 경영진에게 알맞습니다.

## 기본 역할: 역할별로 보고 할 수 있는 것

| 역할 | 요약 |
| --- | --- |
| 관리자 | 모든 것: 회사 설정, 사람, 역할, 연결, 활동 로그 |
| 팀 리드 | 모든 보드를 보고, 팀·고객 필드·자동화를 관리합니다 |
| 멤버 | 자기 업무와 접근할 수 있는 고객 |
| 뷰어 | 보기만 하고 바꾸지 않습니다 |

역할 이름을 바꾸고, 새 역할을 추가하고, 개별 권한을 켜고 끌 수 있습니다.

## 고객 접근

역할마다 어떤 고객에 접근할지 고릅니다.

- **모든 고객**
- **팀의 고객:** 속한 팀의 고객과 자기 고객
- **자기 고객만**

고객 아래의 연락처, 영업 기회, 작업도 같은 규칙을 따릅니다.

## 필드별 접근

일부 역할에게 필드를 숨기거나, 보기만 하고 바꾸지는 못하게 할 수 있습니다. 예를 들어 멤버는 "연간 계약 금액"을 보지만 바꿀 수 없고, "할인"은 관리자만 봅니다.

## 그 사람의 화면으로 보기

설정 → 역할과 권한에서 사람 옆의 **…님의 화면으로 보기**를 누르면, 그 사람이 보는 그대로 Curahold가 열립니다. 그동안에는 아무것도 바꿀 수 없고, 위쪽 띠를 누르면 내 화면으로 돌아옵니다.
