# freee(회계)

freee 회계의 거래처(取引先)와 매출 거래.

## 읽는 내용

고객(프로그램에 있으면 사업자 번호, 이메일, 웹 주소 포함), 기한과 남은 금액이 있는 청구서, 받은 입금 내역입니다. Curahold는 freee에 아무것도 쓰지 않으며, 그곳에서 무엇도 만들거나 바꾸거나 지울 수 없습니다.

## 연결 방법

**설정 → 데이터 소스**에서 **회계 프로그램**을 찾아 **freee 연결**을 선택하세요. 그다음:

1. freee에 로그인하고 연결할 사업소(事業所)를 선택하세요.
2. 접근을 허용하세요. Curahold는 거래처와 매출 거래만 읽습니다.
3. 여기로 돌아와 첫 읽기를 시작하고 연결되지 않은 고객을 확인하세요.

## 제한과 주기

Curahold는 초당 1건 미만으로 요청합니다. 거래처는 매번 전체를 읽고(freee에는 거래처의 "변경 이후" 필터가 없음), 마지막 실행일 이후 바뀐 거래는 다시 읽습니다. 금액은 엔화입니다.

## 문제가 생기면

freee가 연결을 더 이상 받지 않으면(키나 로그인 취소), 설정 → 연결에서 해당 연결에 "문제"가 표시되고 관리자에게 한 번 알립니다. 연결 페이지에서 **다시 연결**을 선택하세요. 요청 한도 응답은 오류가 아닙니다. 실행이 멈추고 위치를 기억한 뒤 다음에 이어서 읽습니다.
