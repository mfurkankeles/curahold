# 요금제와 결제

## 무료 체험

새 회사는 카드 없이 **14일** 동안 모든 기능을 쓸 수 있습니다. 설정 → **결제**에서 남은 일수를 볼 수 있고, 마지막 주에는 앱 맨 위에 안내 줄도 나옵니다.

## 요금제

| | Team | Business |
| --- | --- | --- |
| 보드, 작업, 체크리스트, 자동화 | ✓ | ✓ |
| 고객, 연락처, 영업 기회, 직접 만든 레코드 | ✓ | ✓ |
| 미팅, 타임라인, 헬스 스코어, 비즈니스 리뷰 | ✓ | ✓ |
| 보고서, 대시보드, 목표 | ✓ | ✓ |
| Slack, Teams, Google Chat, 이메일 알림 | ✓ | ✓ |
| CRM 또는 스프레드시트와 양방향 동기화 | | ✓ |
| 고객 포털 | | ✓ |
| 플레이북, 저절로 시작되는 갱신 | | ✓ |

가격은 **전체 권한 좌석** 하나당 월 요금이며 현지 가격이 있는 지역에서는 그 지역 통화(인도 루피, 싱가포르 달러, 튀르키예 리라)로, 그 밖의 지역에서는 미국 달러로 표시되며, 연간 결제 시 더 저렴합니다. 해당되는 경우 세금(VAT, GST, SST 등)이 결제할 때 더해지며 Paddle이 징수하고 납부합니다. **뷰어 좌석은 무료입니다.**

## 요금제 고르기

관리자가 설정 → **결제**를 열고 월간 또는 연간을 고른 뒤 **Team 선택**이나 **Business 선택**을 누릅니다. 결제 페이지(재판매사인 Paddle)가 앱 위에 열리고, 결제가 끝나면 몇 초 안에 페이지에 요금제가 표시됩니다.

## 좌석

청구는 전체 권한 좌석으로 **참여한** 사람을 기준으로 합니다. 아직 수락하지 않은 초대는 청구하지 않습니다. 사람을 추가하면 추가 좌석이 남은 기간만큼 청구되고, 사람을 빼면 다음 청구액이 줄어듭니다. 좌석 수를 직접 바꿀 필요는 없습니다.

## 연간 요금제: 갱신 안내

연간 요금제는 자동으로 1년 더 갱신됩니다. 갱신 **30일 전**에 모든 관리자에게 날짜, 요금제, 좌석 수와 설정 → **결제**로 가는 링크가 담긴 이메일이 갑니다. 약관에 따른 안내이므로 다른 알림을 꺼 두었어도 이메일로 받습니다. 요금제나 좌석 수를 바꾸거나 갱신을 멈추려면 그 날짜 전에 결제 페이지에서 하세요. 취소하면 갱신이 멈추고, 요금제는 결제한 해가 끝날 때까지 계속 쓸 수 있습니다. 무엇을 언제 환불하는지는 [환불 정책](/docs/ko/legal-refunds/)에 있습니다.

## 청구서, 결제 수단, 해지

결제 페이지의 **청구서, 결제 및 해지**를 누르면 이미 로그인된 상태로 Paddle의 고객 포털이 열립니다: 청구서 다운로드, 카드 변경, 해지. 해지한 요금제는 결제한 기간이 끝날 때까지 계속 동작합니다.

Team과 Business, 월간과 연간 사이의 변경도 같은 페이지에서 하며, 차액은 남은 기간만큼 청구(또는 환급)됩니다.

## 요금제별 한도

가격을 낮게 유지하기 위해 요금제마다 운영 비용이 드는 몇 가지에 한도가 있습니다. 설정 → **결제**에서 내 요금제의 수치와 각 항목의 사용량을 볼 수 있습니다:

| 한도 | 한도에 도달하면 |
| --- | --- |
| 전체 권한 좌석 | 새로운 사람은 뷰어(무료)로 참여할 수 있습니다. 전체 권한 좌석을 늘리려면 더 큰 요금제를 선택하세요. |
| 연결된 도구(CRM, 스프레드시트, 지원·회계 도구) | 새 도구를 연결할 때 하나를 제거하거나 더 큰 요금제를 선택하라는 안내가 나옵니다. 이미 연결된 도구에 다시 로그인하는 것은 언제든 가능합니다. |
| 연결된 도구의 동기화 주기 | 요금제마다 주기가 있습니다(Business는 1시간마다). **지금 동기화**는 언제든 쓸 수 있습니다. |
| 파일 공간(전체 권한 좌석당, 회사 공유) | 오래된 파일을 삭제하거나 더 큰 요금제를 선택할 때까지 새 업로드가 멈춥니다. 아무것도 삭제되지 않습니다. |
| 월 CuraAI 답변(전체 권한 좌석당, 공유) | 다음 달까지 CuraAI가 모델 대신 도움말 페이지로 답합니다. |

체험 기간에는 모든 것이 열려 있으며, CuraAI의 월 한도만 더 낮습니다.

## 요금제가 없을 때

요금제 없이 체험이 끝나거나 해지한 요금제가 만료되어도 아무것도 삭제되지 않습니다. 누구나 모든 것을 계속 **읽고 내보낼** 수 있지만, 관리자가 요금제를 고르기 전까지는 아무것도 바꿀 수 없습니다. 요금제를 고르면 멈춘 곳에서 이어서 일합니다.

결제가 실패해도 Paddle이 다시 시도하는 동안, 첫 결제 실패부터 최대 30일까지 모든 것이 계속 동작하며, 맨 위의 안내 줄이 관리자에게 결제 수단을 업데이트하라고 알립니다. 그 뒤에는 결제가 완료될 때까지 요금제가 없을 때처럼 읽기 전용이 됩니다.

## 자체 서버

자체 서버에 설치한 Curahold에는 결제가 없습니다. 모든 기능이 열려 있습니다.
