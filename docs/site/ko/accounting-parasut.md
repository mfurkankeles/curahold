# Paraşüt(회계)

Paraşüt의 고객, 매출 청구서, 입금 내역.

## 읽는 내용

고객(프로그램에 있으면 사업자 번호, 이메일, 웹 주소 포함), 기한과 남은 금액이 있는 청구서, 받은 입금 내역입니다. Curahold는 Paraşüt에 아무것도 쓰지 않으며, 그곳에서 무엇도 만들거나 바꾸거나 지울 수 없습니다.

## 연결 방법

**설정 → 데이터 소스**에서 **회계 프로그램**을 찾아 **Paraşüt 연결**을 선택하세요. 그다음:

1. Paraşüt 지원팀에 회사의 API 접근을 요청하세요. client ID와 client secret을 보내 줍니다.
2. 회사 번호는 주소창의 uygulama.parasut.com/ 뒤에 있습니다.
3. Paraşüt 사용자의 이메일과 비밀번호와 함께 입력하세요. 비밀번호는 키를 받는 데 한 번만 쓰이며 저장되지 않습니다.

## 제한과 주기

Paraşüt는 10초에 약 10건을 허용하고 페이지당 25행을 돌려줍니다. "변경 이후" 필터가 없어 매번 목록 전체를 읽습니다. 작은 회사라면 수십 페이지입니다. 금액은 청구서 통화(TRY, USD, EUR, GBP)로 읽습니다.

## 문제가 생기면

Paraşüt가 연결을 더 이상 받지 않으면(키나 로그인 취소), 설정 → 연결에서 해당 연결에 "문제"가 표시되고 관리자에게 한 번 알립니다. 연결 페이지에서 **다시 연결**을 선택하세요. 요청 한도 응답은 오류가 아닙니다. 실행이 멈추고 위치를 기억한 뒤 다음에 이어서 읽습니다.
