# 고객 포털

고객 포털은 고른 보드를 고객사 사람들에게 엽니다. 고객은 자기 주소(예: `acme.curahold-portal.com`)로 로그인해, 자기 회사에 열려 있는 일과 진행 상황을 보고, 새 요청을 열고 답장합니다.

## 고객이 보는 것과 절대 보지 못하는 것

| 보는 것 | 절대 보지 못하는 것 |
|---|---|
| 자기 회사의 작업 중 **공유된 것** | 다른 고객의 작업 |
| 제목, 설명, 상태(열에 정한 이름으로) | 내부 메모와 내부 댓글 |
| **고객에게 답변**으로 쓴 댓글 | 우리 팀, 역할, 다른 사람 |
| 보드에서 허용한 세부 정보(마감일, 우선순위, 담당자) | 고객 필드, 거래, 헬스 스코어, 레코드 |
| | 다른 보드, 다른 회사, Curahold 자체 |

포털은 별도 도메인에서 동작하므로, 앱의 세션, 쿠키, API에 전혀 닿을 수 없습니다. 포털 요청 뒤의 데이터베이스 역할은 어떤 테이블도 읽을 수 없고, 로그인한 사람의 회사 데이터만 돌려주는 포털 함수만 호출할 수 있습니다.

## 켜기(관리자)

1. **설정 → 고객 포털 → 고객 포털 사용 중.** 고객이 로그인할 주소가 여기 표시됩니다.
2. 열고 싶은 **보드의 설정** → **고객 포털**:
   - **이 보드를 고객에게 공개**
   - **새 요청이 들어가는 열:** 열을 고릅니다. 새 요청은 고객 담당자에게 맡겨집니다.
   - **고객에게 표시되는 열 이름:** 예를 들어 "법무 검토 대기" 대신 "검토 중". 비워 두면 열 이름이 그대로 나옵니다.
   - **고객에게 표시되는 세부 정보:** 마감일, 우선순위, 담당자.

비공개 보드는 열 수 없습니다. 스위치를 끄면 모두에게 포털이 즉시 닫힙니다.

## 사람 초대하기

**설정 → 고객 포털 → 로그인할 수 있는 사람**이나 고객 페이지의 **고객 포털** 영역에서 이름과 이메일을 입력하고 **초대**를 누르세요. 고객 담당자와 관리자가 초대할 수 있습니다.

- 초대는 7일 동안 한 번만 쓸 수 있습니다. 그 뒤로는 회사가 허용한 방법(아래)으로 로그인합니다.
- 우리 회사 사람의 주소는 초대할 수 없습니다. 포털은 고객을 위한 것입니다.
- **끄기**를 누르면 접근과 열린 세션이 즉시 끝납니다.

## 로그인 방법

**설정 → 고객 포털 → 고객 로그인 방법**에서 고객에게 맞는 방법을 고르세요.

| 방법 | 동작 방식 |
|---|---|
| **이메일 코드 및 링크** | 6자리 코드와 링크가 담긴 이메일 한 통. 각각 30분 동안 한 번 쓸 수 있습니다. 코드가 있으면 휴대폰으로 이메일을 읽고 컴퓨터에서 로그인할 수 있습니다. |
| **Google** | 고객 회사의 Google 계정. 회사가 계정을 닫으면 포털도 닫힙니다. |
| **Microsoft** | Microsoft 365 계정. 처음 Microsoft로 로그인할 때 이메일 코드로 한 번 확인하고, 그 뒤로는 계정 자체로 알아봅니다. |
| **패스키** | 지문, 얼굴, 기기 PIN. 가장 안전한 방법이며, 첫 로그인 후 **내 계정**에서 추가합니다. 패스키는 그 포털의 주소에서만 동작하고, 비슷하게 꾸민 사이트에서는 절대 동작하지 않습니다. |
| **비밀번호** | 원하는 고객을 위해(기본은 꺼짐). 10자 이상, 다섯 번 틀리면 15분 동안 잠기며, "비밀번호를 잊으셨나요?"로 이메일을 통해 재설정합니다. |

- **로그인 유지 기간:** 1, 7, 30(기본), 90일.
- **로그인 알림:** Google, Microsoft, 패스키, 비밀번호로 로그인하면 "새 로그인" 이메일을 보냅니다(끌 수 있음).
- 방법을 끄면 그 방법으로 연 세션이 끝나고, 유지 기간을 줄이면 더 오래된 세션이 끝납니다. 이메일, Google, Microsoft, 비밀번호 중 최소 하나는 켜 두어야 합니다.
- 로그인 양식은 어떤 주소에 접근 권한이 있는지 절대 알려 주지 않으며, 한 주소로는 한 시간에 최대 5통까지 보냅니다.
- **내 계정**에서 패스키 추가, 비밀번호 설정, Google/Microsoft 연결 해제, 모든 기기에서 로그아웃을 할 수 있습니다.

## 작업 공유와 답장

- 고객이 연 요청은 저절로 공유됩니다.
- 우리 팀이 연 작업을 보여 주려면 작업 패널에서 **고객과 공유됨**을 체크하세요(작업에 고객이 있고, 공개된 보드에 있어야 합니다).
- 공유된 작업에 댓글을 쓸 때 **내부 메모**(기본) 또는 **고객에게 답변**을 고릅니다. 고객에게 보낸 답변은 주황색 선과 "고객에게 표시됨"으로 표시되고 고객에게 이메일로도 갑니다.
- 고객이 쓴 글은 "고객" 라벨과 함께 표시되고, 작업 담당자에게 알림으로 갑니다.
- 작업의 고객이 바뀌면 공유가 저절로 꺼집니다. 한 고객의 대화가 다른 고객에게 넘어가는 일은 없습니다.

## 한도

한 사람이 하루에 요청은 30개까지 열고, 답장은 200개까지 쓸 수 있습니다.
