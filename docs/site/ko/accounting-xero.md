# Xero(회계)

Xero의 고객, 매출 청구서, 입금 내역.

## 읽는 내용

고객(프로그램에 있으면 사업자 번호, 이메일, 웹 주소 포함), 기한과 남은 금액이 있는 청구서, 받은 입금 내역입니다. Curahold는 Xero에 아무것도 쓰지 않으며, 그곳에서 무엇도 만들거나 바꾸거나 지울 수 없습니다.

## 연결 방법

**설정 → 데이터 소스**에서 **회계 프로그램**을 찾아 **Xero 연결**을 선택하세요. 그다음:

1. Xero에 로그인하고 연결할 조직을 선택하세요.
2. 연락처와 거래의 읽기 권한을 허용하세요. Curahold는 Xero의 어떤 것도 바꿀 수 없습니다.
3. 여기로 돌아와 첫 읽기를 시작하고 연결되지 않은 고객을 확인하세요.

## 제한과 주기

Xero는 조직당 분당 60회 호출과 일일 한도(무료 개발자 등급은 1,000회)를 허용합니다. Curahold는 두 한도 아래로 속도를 맞추며, 하루 한도에 이르면 다음 실행에서 이어 갑니다. 변경 사항은 매시간 읽습니다.

## 문제가 생기면

Xero가 연결을 더 이상 받지 않으면(키나 로그인 취소), 설정 → 연결에서 해당 연결에 "문제"가 표시되고 관리자에게 한 번 알립니다. 연결 페이지에서 **다시 연결**을 선택하세요. 요청 한도 응답은 오류가 아닙니다. 실행이 멈추고 위치를 기억한 뒤 다음에 이어서 읽습니다.
