# 홈 페이지와 카드

홈은 Curahold를 여는 순간 자기 일을 볼 수 있도록 있는 곳입니다. 페이지는 카드로 이루어지고, 역할마다 자기 홈 페이지에서 시작합니다.

## 카드

| 카드 | 보여 주는 것 |
| --- | --- |
| 내 진행 중 작업 | 끝나지 않은 내 작업, 지연된 것부터 |
| 다가오는 갱신 | 정한 일수 안에 갱신하는 고객과 그 총 금액 |
| 주의 필요 | 헬스가 위험하거나 주시가 필요한 고객 |
| 연락 끊긴 고객 | 한동안 활동이 없는 고객 |
| 이해관계자 리스크 | 반대자와 회의적인 사람, 핵심 지지자가 없는 고객 |
| 숫자 | 고객 수나 총 금액 같은 값 하나 |
| 분포 | 선택 필드로 나눈 고객 |
| 팀 업무량 | 사람별 고객, 열린 업무, 지연된 업무, 위험한 업무 |
| 연결 | CRM과 스프레드시트 동기화 상태 |
| 메모 | 팀을 위한 짧은 공지나 링크 |

대부분의 카드는 "나", "내 팀", "전체" 중에서 고를 수 있습니다. 카드는 보는 사람이 볼 수 있는 범위 안에서 계산하므로, 같은 페이지를 열어도 권한이 다르면 다른 숫자가 보입니다.

## 페이지 편집

관리자는 **페이지 편집**으로 카드를 추가하고 순서와 크기를 정하며, 어떤 역할이 그 페이지에서 시작할지 고릅니다. 페이지를 일부 역할에게만 보여 줄 수도 있습니다.

> **팁:** 어떤 역할이 무엇을 보는지 확인하려면 설정 → 역할과 권한에서 **…님의 화면으로 보기**를 쓰세요. 그 사람의 화면이 읽기 전용으로 열립니다.
