# Claude와 ChatGPT 연결하기

Curahold를 Claude, ChatGPT 또는 MCP를 지원하는 어시스턴트에 연결하면, 어시스턴트가 나를 대신해 Curahold에서 정보를 찾고 일을 처리할 수 있습니다.

## 이렇게 물어볼 수 있습니다

- "앞으로 60일 안에 갱신하는 내 고객 중 위험해 보이는 곳은?"
- "하버라인 은행의 이해관계자와 열린 업무를 요약해 줘."
- "내 고객 포트폴리오를 5장짜리 요약으로 만들어 줘."
- "박지은에게 내일까지 벨토 모빌리티의 사용량 감소를 살펴보는 작업을 열어 줘."
- "이 작업을 완료로 표시하고 '제안서 보냄'이라고 댓글 달아 줘."

## 연결하는 방법

1. Curahold에서 **내 설정**을 열고 **커넥터 주소**를 복사합니다. `https://yourcompany.curahold.com/mcp`와 같은 형태입니다.
2. **Claude:** Settings → Connectors → Add custom connector. 주소를 붙여 넣고 연결합니다.
   **ChatGPT:** 커넥터 설정에서 이 주소로 사용자 지정(MCP) 커넥터를 추가합니다. 일부 요금제에서는 먼저 개발자 모드를 켜야 합니다.
3. Curahold의 권한 화면이 열립니다. 로그인하고, 어시스턴트가 할 수 있는 일을 확인한 뒤 **허용**을 누르세요.

## 안전

- 어시스턴트는 **나로서** 일합니다. 내가 볼 수 있는 것만 보고, 내가 바꿀 수 있는 것만 바꿉니다. 역할과 필드 규칙이 그대로 적용됩니다.
- 권한 화면에서 "변경도 허용"의 체크를 해제하면 어시스턴트는 읽기만 합니다. 뷰어 좌석에서는 어차피 읽기만 합니다.
- 내 설정 → API 키 및 연결된 앱에서 언제든 연결을 끊을 수 있습니다.
- 어시스턴트는 내 Claude 또는 ChatGPT 요금제로 동작하며, Curahold는 AI에 대해 추가 요금을 받지 않습니다.
