# Odoo(회계)

Odoo Online, Odoo.sh 또는 자체 서버의 고객, 청구서, 입금 내역.

## 읽는 내용

고객(프로그램에 있으면 사업자 번호, 이메일, 웹 주소 포함), 기한과 남은 금액이 있는 청구서, 받은 입금 내역입니다. Curahold는 Odoo에 아무것도 쓰지 않으며, 그곳에서 무엇도 만들거나 바꾸거나 지울 수 없습니다.

## 연결 방법

**설정 → 데이터 소스**에서 **회계 프로그램**을 찾아 **Odoo 연결**을 선택하세요. 그다음:

1. Odoo에서 프로필 → 환경설정 → 계정 보안을 열고 API 키를 만드세요.
2. Odoo 주소와 로그인 이름을 적어 두세요. Odoo.sh나 자체 서버라면 데이터베이스 이름도 필요합니다.
3. 아래에 입력하세요. Odoo Online에서는 API 접근에 Custom 요금제가 필요합니다(Odoo 규정).

## 제한과 주기

Odoo는 고정된 한도를 공개하지 않습니다. Curahold는 작은 서버에 부담을 주지 않도록 초당 약 2건으로 요청합니다. Odoo 19 이상은 JSON-2 API로, 이전 버전은 JSON-RPC로 읽습니다(이 경우 데이터베이스 이름이 필요). 변경 사항은 매시간 읽습니다.

## 문제가 생기면

Odoo가 연결을 더 이상 받지 않으면(키나 로그인 취소), 설정 → 연결에서 해당 연결에 "문제"가 표시되고 관리자에게 한 번 알립니다. 연결 페이지에서 **다시 연결**을 선택하세요. 요청 한도 응답은 오류가 아닙니다. 실행이 멈추고 위치를 기억한 뒤 다음에 이어서 읽습니다.
