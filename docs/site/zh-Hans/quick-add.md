# 快速添加和快捷键

按 **N**（或左侧的 **+ 新建 → 任务**、列底部的 **添加任务**、手机上底部的 **+**）会打开 **新任务** 窗口。标题下方填写详细信息：描述、客户、任务所属的记录（商机、协议等）、负责人、截止日期、优先级、重复、看板和列，以及看板自己的字段。从某一列打开时，该列已经选好；从客户页面打开时，客户已经选好。

不必逐个填写字段；按想到的样子写下标题就够了：

> 续约电话 friday @林悦 #维途 !high

这一行就填好了字段：负责人林悦、客户维途出行、截止日期周五、优先级高。从标题中填入的字段会显示 **来自标题**。如果手动修改某个字段，对应的词会从标题中移除，字段保留你的选择。按 **Enter** 添加任务；在其他字段中则按 **Ctrl Enter**（Mac 上为 ⌘ Enter）。

## 可以写什么

除土耳其语外，在所有语言中，日期、重复和优先级的词都用英语书写。

| 内容 | 写法 | 示例 |
| --- | --- | --- |
| 截止日期 | 日常用语 | today, tomorrow, friday, next week, weekend, end of month, nov 15, 15.11, in 3 days |
| 人员 | @ 加姓名 | @林悦、@王浩然、@me |
| 客户 | # 加名称 | #维途、#港线银行 |
| 优先级 | ! 加级别 | !urgent, !high, !low |
| 重复 | every … | every day, every week, every monday, every 2 weeks, monthly |

在中文句子中，请在以 @ 或 # 开头的词前后加一个空格。

- 输入 **@** 或 **#** 会打开一个列表；用方向键选择，按 **Enter** 或 **Tab** 确认。
- 标签上的 **×**：把人员、客户或优先级从这一行中去掉。被识别为日期或节奏的词会留在标题中（加上引号）。如果某个词绝不应被识别为日期，请自己给它加上引号：*"may" 活动报告*。
- 没有匹配到任何人的 @ 或 # 会显示黄色边框，并留在标题中。

## 在哪里添加很重要

- 从 **我的任务** 添加，任务就是你的。
- 在 **看板** 上，任务进入看板的第一列；可以在窗口底部更改看板和列。
- 在 **客户页面** 上，任务会关联到该客户。
- 在 **日历** 上，点某一天的 **+** 会把任务放在那一天。

## 一次添加多个任务

粘贴几行文字（比如会议记录）：每一行都会成为一个单独的任务，添加之前会全部显示出来。按 **Ctrl Enter**（Mac 上为 **⌘ Enter**）全部添加。勾选“继续添加”后，窗口会保持打开。

## 一键完成

在列表和卡片上，每个任务前面都有一个圆形勾选框：点一下，任务就会移到看板的“完成”列。点错了？在出现的提示中点 **撤销**。任务窗口中的 **标记为完成** 按钮作用相同。

## 键盘快捷键

除了在输入框中打字时，快捷键在任何地方都有效。按 **?** 也可以在应用内查看此列表。

| 按键 | 作用 |
| --- | --- |
| N | 新任务 |
| Ctrl K 或 / | 搜索并跳转 |
| ? | 键盘快捷键 |
| Esc | 关闭当前打开的内容 |
| 先 G 再 H | 主页 |
| 先 G 再 M | 我的任务 |
| 先 G 再 C | 日历 |
| 先 G 再 A | 客户 |
| 先 G 再 P | 个人资料和通知 |
| 先 G 再 S | 设置 |

## 在手机上

底部有五个按钮：主页、我的任务、中间的 **+**、客户和日历。看板、设置和你的菜单在左上角的 ☰ 里。

## 外观

在你的菜单（左下角你的名字）中选择 **浅色**、**深色** 或 **跟随此设备**。选择会保存在这台设备上。
