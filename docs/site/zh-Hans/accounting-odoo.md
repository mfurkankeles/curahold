# Odoo（会计）

来自 Odoo Online、Odoo.sh 或自建服务器的客户、发票和收款。

## 读取哪些内容

客户（以及软件中保存的税号、邮箱和网址）、带到期日和未付金额的发票，以及收到的款项。Curahold 绝不会写入 Odoo：它无法在那里创建、更改或删除任何内容。

## 连接

在**设置 → 数据源**中找到**会计软件**，选择**连接 Odoo**。然后：

1. 在 Odoo 中打开你的个人资料 → 偏好设置 → 账户安全，创建一个 API 密钥。
2. 记下你的 Odoo 地址和登录名。在 Odoo.sh 或自建服务器上，还要记下数据库名称。
3. 在下面填写。在 Odoo Online 上，API 访问需要 Custom 方案（Odoo 的规定）。

## 限制与时间

Odoo 没有公布固定限制；Curahold 保持每秒约两次请求，避免给小型服务器带来压力。Odoo 19 及以后版本通过 JSON-2 API 读取，较早版本通过 JSON-RPC 读取（此时需要数据库名称）。每小时读取一次变更。

## 出现问题时

如果 Odoo 不再接受连接（密钥或登录被撤销），该连接会在 设置 → 连接 中标记为"有问题"，并通知管理员一次；在其页面上选择**重新连接**。速率限制的回复不是错误：本次运行会停下、记住位置，下次继续。
