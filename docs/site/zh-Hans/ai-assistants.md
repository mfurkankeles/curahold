# 连接 Claude 和 ChatGPT

把 Curahold 连接到 Claude、ChatGPT 或任何支持 MCP 的助手，助手就能以你的身份在 Curahold 中查找信息、完成工作。

## 可以问什么

- “我的客户中，哪些会在未来 60 天内续约而且看起来有风险？”
- “总结一下港线银行的关键干系人和未完成的工作。”
- “把我的客户组合做成一份 5 页的摘要。”
- “给陈思雨开一个任务，明天截止，调查维途出行的使用量下降。”
- “把这个任务标记为完成，并评论‘方案已发送’。”

## 如何连接

1. 在 Curahold 中打开 **你的设置**，复制 **连接器地址**。它形如 `https://yourcompany.curahold.com/mcp`。
2. **Claude：** Settings → Connectors → Add custom connector。粘贴地址并连接。
   **ChatGPT：** 在连接器设置中，用这个地址添加一个自定义（MCP）连接器。部分套餐需要先开启开发者模式。
3. Curahold 的授权页面会打开。登录，确认助手可以做什么，然后选择 **允许**。

## 安全

- 助手以 **你的身份** 工作。它只能看到你能看到的内容，只能修改你能修改的内容。你的角色和字段规则照常生效。
- 在授权页面上取消勾选“同时允许修改”，助手就只能读取。在查看者席位上，它本来就只能读取。
- 随时可以在“你的设置”→ API 密钥和已连接的应用 中断开连接。
- 助手使用你自己的 Claude 或 ChatGPT 套餐；Curahold 不会为 AI 额外收费。
