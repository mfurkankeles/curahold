# 安全和隐私

## 公司之间互相看不到

每个查询都在数据库的行级安全规则下运行。任何方式都无法从另一家公司的地址、API 或连接器读取一家公司的数据。角色和字段规则也在同一层强制执行。

## 会话和设备

会话与设备绑定；复制的 Cookie 在另一台机器上无效。超过设备数量限制时，最早的会话会被退出。在“你的设置”→ 设备 中查看和结束你的会话。

## 通行密钥和第二步验证

除了邮件链接，你还可以用 **通行密钥**（指纹、面容或设备 PIN）登录，并添加 **第二步验证**：一个身份验证器应用，以及十个在手机丢失时使用的一次性恢复码。在 **我的设备 → 登录安全** 中设置，也可以在那里一次性退出所有其他设备。管理员可以在 **“设置”→ 登录** 中要求管理员或所有人使用第二步验证；每次登录时都会在服务器上检查。通过单点登录登录的人不会被再次询问：由身份提供方负责。不会有人被锁在外面：管理员可以重置某人的第二步验证，自托管安装则可以在服务器环境中重置（`RESET_SECOND_STEP`）。

当你的登录已超过十分钟时，更改角色、单点登录或 SCIM、创建 API 密钥、导出或清除个人数据、移除人员以及导出活动日志，都会要求你确认是本人（通行密钥、应用验证码或邮件验证码）。

## 保存在设备上的内容

为了让你在没有网络时也能阅读，应用会把你最近看过的列表副本保存在浏览器自己的存储中（任务、看板、客户、收件箱；不包括附件和设置）。副本只留在这台设备和这个浏览器中，不会发送到任何地方。退出登录时，或在服务器上结束会话后的第一次连接时，副本会被删除。在共用电脑上，用完后请退出登录。

## 活动日志

登录、第二步验证、人员和角色的更改、连接、API 密钥、webhook 以及个人数据操作都会写入活动日志，见设置 → 活动日志。条目永远不会被更改，即使应用使用的数据库角色也无法删除条目；12 个月后由夜间清理移除（数据库会拒绝删除任何不足 90 天的条目）。**导出日志**会附带连续的 SHA-256 指纹下载；最终指纹也会写入日志，以便日后核对副本。

## 客户门户

客户门户运行在独立的域名上，拥有自己的会话和 Cookie。门户请求背后的数据库角色对任何表都没有权限；它只能调用返回已登录者所在公司共享数据的函数。详情：[客户门户](/docs/zh-Hans/customer-portal/)。

## Curahold 支持人员的访问

Curahold 支持人员只有在某人同意的情况下才会进入公司：此人在帮助请求中勾选选项，并选择时长（24 小时到 7 天）。支持人员看到的就是此人看到的，而且只能查看：永远不能修改任何内容。选定的时间一到，访问即结束，也可以随时关闭。每一次访问，以及支持人员在此期间查看的内容，都会连同支持人员的姓名写入活动日志。管理员可以在 **“设置”→ 安全 → 支持访问** 中把它限制为仅管理员，或将其关闭。详情：[获取帮助](/docs/zh-Hans/getting-help/)。

## 个人数据

在“设置”→ 人员 中，每个人的菜单提供：

- **下载个人数据：** 与此人相关的所有内容，打包成一个文件。
- **清除个人数据：** 删除姓名和邮箱；此人完成的工作会匿名保留。请先把此人的客户和未完成任务交给其他人。
- **清除**还会移除此人向 CuraAI 提出的问题、通知、聊天关联、通行密钥和第二步验证、会话录像，以及 AI 团队笔记中提到其地址或全名之处。法律要求保留的内容会保留：发票、代表公司接受条款的记录，以及不含地址（仅保留其指纹）的同意记录。
- **你的客户那边的人员**（设置 → 客户门户 → 可登录的人员）：负责隐私的管理员可以**下载数据**或**清除个人数据**。清除会删除门户账户本身；其写下的内容会保留，但不显示姓名。

### 删除整个公司

管理员可以在**设置 → 公司 → 删除公司**中输入公司地址提出申请。30 天内不会删除任何内容：公司照常运作，你仍可导出，任何管理员都可以取消。之后所有内容（包括文件和连接密钥）都会被永久删除，并保留一份列出删除内容的删除证明（不含姓名或地址）。发票会按税法要求保留。备份按托管服务商的周期滚动删除。

### 个人数据请求

在**设置 → 公司 → 个人数据请求**中，拥有隐私权限的人员会记录个人就其数据提出的每一项请求，并注明适用的法律：查阅、更正、删除、限制处理、反对处理、数据可携或撤回同意。截止日期按该法律计算（例如 KVKK 为 30 天，GDPR 为一个日历月，韩国 PIPA 为 10 天），逾期的请求会以红色和图标标出。处理完成后，将请求标记为已答复或已拒绝；每次更改都会记入活动日志。具体处理请使用该人员的导出和删除操作。

## 数据保留时长

| 数据 | 保留时长 |
| --- | --- |
| 通知 | 90 天 |
| 已结束的会话 | 90 天 |
| 同步历史 | 90 天 |
| [回收站](/docs/zh-Hans/trash/) 中已删除的客户、记录、任务等 | 30 天，之后连同文件一起清除；管理员可以提前清除 |
| 导入的撤销数据 | 30 天 |
| webhook 投递记录 | 7 天 |
| 错误记录（出了什么问题、在哪里——绝不包含请求内容） | 30 天 |
| 已吊销的 API 密钥 | 30 天 |
| 活动日志 | 12 个月 |
| 已答复或拒绝的个人数据请求 | 结案后 3 年 |
| 帮助请求及其消息和文件 | 最后一次更改后 24 个月 |
| 向 CuraAI 提出的问题 | 按你的公司选择（未更改则为 30 天） |
| 已删除的公司 | 申请 30 天后清除 |

## 保存的机密

CRM 和聊天连接的凭据，以及 webhook 签名密钥，都加密保存。API 密钥只保存摘要：密钥本身只显示一次，之后再也无法查看。

## 单点登录（SSO）和 SCIM {#sso}

在设置 → **单点登录（SSO）** 中：选择**协议**，把**请将以下信息提供给你的身份提供商**下的值交给身份提供商，填写**你的身份提供商信息**，保存，然后点击**测试登录**。测试不会让任何人登录，也不会开启 SSO。只有用当前保存的同一组信息测试通过，并且有一位设置了通行密钥或验证器应用的备用管理员后，才能开启**要求此公司使用 SSO**。

测试未通过时会说明原因：

- 客户端密钥被拒绝（在身份提供商那边更新过）：把新的粘贴到**客户端密钥**并保存；
- 签名不一致（身份提供商更新了密钥或证书）：如果是 SAML，把新证书粘贴到**IdP 签名证书**；OpenID Connect 会自动获取新密钥；
- 应答是给另一个应用的或已过期：检查**颁发者（Issuer）**、**客户端 ID**和身份提供商的时钟；
- 无法连接身份提供商：检查**令牌端点**和**JWKS URL**，然后等一分钟。

登录的人只会看到身份提供商未完成登录，并回到登录页。

**SCIM 用户预配**：**生成令牌**只显示一次令牌；把它和**SCIM 基础 URL**一起交给身份提供商。在那边被停用的人会立即失去所有会话和 API 密钥，改名也会同步过来。生成新令牌会立即停用旧令牌。
