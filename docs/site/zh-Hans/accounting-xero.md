# Xero（会计）

来自 Xero 的客户、销售发票和收款。

## 读取哪些内容

客户（以及软件中保存的税号、邮箱和网址）、带到期日和未付金额的发票，以及收到的款项。Curahold 绝不会写入 Xero：它无法在那里创建、更改或删除任何内容。

## 连接

在**设置 → 数据源**中找到**会计软件**，选择**连接 Xero**。然后：

1. 登录 Xero 并选择要连接的组织。
2. 允许读取联系人和交易；Curahold 无法更改 Xero 中的任何内容。
3. 回到这里后，开始首次读取，并检查未能匹配的客户。

## 限制与时间

Xero 允许每个组织每分钟 60 次调用并设每日额度（Xero 免费开发者层级为 1,000 次）。Curahold 控制速度，始终低于这两个限制；达到当天额度时会在下一次运行中继续。每小时读取一次变更。

## 出现问题时

如果 Xero 不再接受连接（密钥或登录被撤销），该连接会在 设置 → 连接 中标记为"有问题"，并通知管理员一次；在其页面上选择**重新连接**。速率限制的回复不是错误：本次运行会停下、记住位置，下次继续。
