# 套餐和账单

## 免费试用

新公司可以免费使用全部功能 **14 天**，无需绑卡。“设置”→ **账单** 会显示还剩几天；最后一周，应用顶部也会有一行提示。

## 套餐

| | Team | Business |
| --- | --- | --- |
| 看板、任务、清单和自动化 | ✓ | ✓ |
| 客户、联系人、商机和你们自己的记录 | ✓ | ✓ |
| 会议、时间线、健康评分和业务回顾 | ✓ | ✓ |
| 报表、仪表板和目标 | ✓ | ✓ |
| Slack、Teams、Google Chat 和邮件通知 | ✓ | ✓ |
| 与 CRM 或电子表格双向同步 | | ✓ |
| 客户门户 | | ✓ |
| 行动手册，以及自动启动的续约 | | ✓ |

价格按每个 **完整席位** 每月计算，以美元计价，按年付款更便宜；结账时另加税费。**查看者席位免费。**

## 选择套餐

管理员打开“设置”→ **账单**，选择按月或按年，然后点击 **选择Team** 或 **选择Business**。付款页面（由我们的经销商 Paddle 提供）会在应用上方打开；付款完成后，几秒内套餐就会显示在页面上。

## 席位

账单按以完整席位 **加入** 的人员计算：尚未接受的邀请不计费。添加一个人，新增的席位按本周期剩余时间计费；移除一个人，下一期账单就会减少。没有人需要手动修改席位数。

## 发票、付款方式、取消

账单页面上的 **发票、付款和取消** 会打开 Paddle 的客户门户，并且已经登录：下载发票、更换银行卡、取消订阅。取消的套餐会一直可用到已付费周期结束。

在 Team 和 Business 之间、或按月和按年之间切换，也在同一页面完成；差额按本周期剩余时间计费（或退还）。

## 没有套餐时

试用结束但没有选择套餐，或已取消的套餐到期时，不会删除任何内容。所有人仍然可以 **查看和导出** 全部内容；在管理员选择套餐之前不能做任何修改，选择之后，工作会从停下的地方继续。

如果付款失败，在 Paddle 重试期间一切照常可用；顶部的提示会请管理员更新付款方式。

## 你们自己的服务器

安装在你们自己服务器上的 Curahold 没有账单：所有功能都开放。
