# freee（会计）

来自 freee 会计的往来单位（取引先）和销售交易。

## 读取哪些内容

客户（以及软件中保存的税号、邮箱和网址）、带到期日和未付金额的发票，以及收到的款项。Curahold 绝不会写入 freee：它无法在那里创建、更改或删除任何内容。

## 连接

在**设置 → 数据源**中找到**会计软件**，选择**连接 freee**。然后：

1. 登录 freee 并选择要连接的事业所。
2. 允许访问；Curahold 只读取往来单位和销售交易。
3. 回到这里后，开始首次读取，并检查未能匹配的客户。

## 限制与时间

Curahold 保持每秒少于一次请求。往来单位每次完整读取（freee 不提供"自某时起变更"筛选）；在上次运行当天或之后变更的交易会重新读取。金额以日元计。

## 出现问题时

如果 freee 不再接受连接（密钥或登录被撤销），该连接会在 设置 → 连接 中标记为"有问题"，并通知管理员一次；在其页面上选择**重新连接**。速率限制的回复不是错误：本次运行会停下、记住位置，下次继续。
