# 客户门户

客户门户把选定的看板开放给客户公司的人员。他们在自己的地址登录（例如 `acme.curahold-portal.com`），查看本公司有哪些事项在处理、进展如何，提交新请求并回复。

## 客户能看到什么，永远看不到什么

| 能看到 | 永远看不到 |
|---|---|
| 本公司 **与其共享** 的任务 | 其他客户的任何任务 |
| 标题、描述、状态（显示你为该列设定的名称） | 内部备注和内部评论 |
| 以 **回复客户** 方式写的评论 | 你的团队、角色和其他人员 |
| 你在看板上允许显示的详情（截止日期、优先级、负责人） | 客户字段、交易、健康评分、记录 |
| | 其他看板、其他公司以及 Curahold 本身 |

门户运行在独立的域名上：从门户根本无法访问应用的会话、Cookie 和 API。门户请求背后的数据库角色不能读取任何表；它只能调用门户函数，而这些函数只返回已登录者所在公司的数据。

## 开启（管理员）

1. **“设置”→ 客户门户 → 客户门户已开启。** 客户登录的地址会显示在这里。
2. 在要开放的 **看板的设置** → **客户门户** 中：
   - **向客户开放此看板**
   - **新请求进入：** 选择一列。新请求会分配给该客户的负责人。
   - **客户看到的各列名称：** 比如用“审核中”代替“等待法务”。留空则显示列本身的名称。
   - **客户可见的详情：** 截止日期、优先级、负责人。

   更快的方法（还没有开放任何看板时）：**设置 → 客户门户** 会列出你的看板；在请求要进入的看板上点击**向客户开放 …**（请求会进入它的第一列）。

私有看板不能开放。关闭开关会立即对所有人关闭门户。

## 邀请人员

在 **“设置”→ 客户门户 → 可登录的人员** 中，或在客户页面的 **客户门户** 部分：填写姓名和邮箱，然后点 **邀请**。客户的负责人和管理员可以发出邀请。

- 邀请只能使用一次，有效期 7 天。之后，人员可以用公司允许的任一方式登录（见下文）。
- 不能邀请你们公司内部人员的地址；门户是给客户用的。
- **停用** 会立即终止其访问权限和已打开的会话。

## 登录方式

在 **“设置”→ 客户门户 → 客户如何登录** 中，选择适合你们客户的方式：

| 方式 | 工作原理 |
|---|---|
| **邮件验证码和链接** | 一封包含六位验证码和链接的邮件，各自只能使用一次，30 分钟内有效。有了验证码，就可以在手机上看邮件、在电脑上登录。 |
| **Google** | 对方公司的 Google 账户。如果对方公司关闭了该账户，门户也会对其关闭。 |
| **Microsoft** | 对方的 Microsoft 365 账户。第一次用 Microsoft 登录时，会用邮件验证码确认一次；之后直接识别该账户。 |
| **通行密钥** | 指纹、面容或设备 PIN。最安全的方式；首次登录后可在 **你的账户** 中添加。通行密钥只在该门户的地址上有效，在仿冒网站上永远无效。 |
| **密码** | 供有需要的客户使用（默认关闭）。至少 10 个字符；连续五次输错会锁定 15 分钟；“忘记密码？”可通过邮件重置。 |

- **保持登录：** 1、7、30（默认）或 90 天。
- **登录提醒：** 用 Google、Microsoft、通行密钥或密码登录后，此人会收到一封“新登录”邮件（可以关闭）。
- 关闭某种方式会结束用该方式打开的会话；缩短保持登录的时间会结束较早的会话。至少要保留一种登录方式（邮件、Google、Microsoft 或密码）。
- 登录表单永远不会透露某个地址是否有访问权限，同一地址每小时最多收到 5 封邮件。
- 在 **你的账户** 中，人员可以添加通行密钥、设置密码、解除与 Google/Microsoft 的关联，或在所有设备上退出登录。

## 共享任务和回复

- 客户提交的请求会自动共享。
- 要展示你们团队创建的任务，在任务面板中勾选 **已与客户共享**（任务需要关联客户，并位于已开放的看板上）。
- 在共享任务上发表评论时，选择 **内部备注**（默认）或 **回复客户**。回复客户的内容会以橙色线条和“客户可见”标出，并通过邮件发送给客户。
- 客户写的内容会带有“客户”标签，并以通知形式发送给任务的负责人。
- 任务关联的客户变更后，共享会自动关闭：一个客户的对话绝不会转到另一个客户那里。

## 客户发送的文件

客户只能向与其共享的请求和工单，以及其入门计划的步骤发送文件。其他地方都不行。

- 支持文档、图片、表格、CSV、PDF 和 ZIP，每个最大 25 MB。每个文件都会按类型和开头字节检查，并且始终以下载方式打开。
- 客户总共能发送多少，在设置 → **客户门户** → **客户发送的文件**中设定（默认 2,048 MB）。用满后，客户会被告知改用其他方式发送。
- 客户发送的每个文件都会显示在该客户的时间线上。

## 限制

每人每天最多可提交 30 个请求、写 200 条回复。
