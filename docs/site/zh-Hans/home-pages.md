# 主页和卡片

主页的作用是让每个人一打开 Curahold 就看到自己的工作。每个页面由卡片组成，每个角色都从自己的主页开始。

## 卡片

| 卡片 | 显示内容 |
| --- | --- |
| 我的未完成任务 | 你尚未完成的任务，逾期的排在前面 |
| 即将续约 | 在你选定的天数内续约的客户及其总金额 |
| 需要关注 | 健康度有风险或值得关注的客户 |
| 失去联系 | 一段时间没有任何活动的客户 |
| 干系人风险 | 阻碍者和怀疑者，以及没有核心支持者的客户 |
| 单个数字 | 一个数值，比如客户数或总金额 |
| 分布 | 按某个选项字段划分的客户 |
| 团队负荷 | 每个人的客户数，以及未完成、逾期和有风险的工作 |
| 连接 | CRM 和电子表格同步的状态 |
| 备注 | 给团队的简短公告或链接 |

大多数卡片都可以选择“我的”“我团队的”或“所有人的”。卡片只在查看者有权看到的范围内计算：两个人打开同一个页面，如果权限不同，看到的数字也不同。

## 编辑页面

管理员用 **编辑页面** 添加卡片、调整顺序和大小，并选择哪些角色从这个页面开始。页面也可以只对部分角色显示。

> **提示：** 想确认某个角色能看到什么，可以在“设置”→ 角色和权限 中使用 **以…的视角查看**。它会以只读方式打开那个人的界面。
