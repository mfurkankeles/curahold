# Paraşüt（会计）

来自 Paraşüt 的客户、销售发票和收款。

## 读取哪些内容

客户（以及软件中保存的税号、邮箱和网址）、带到期日和未付金额的发票，以及收到的款项。Curahold 绝不会写入 Paraşüt：它无法在那里创建、更改或删除任何内容。

## 连接

在**设置 → 数据源**中找到**会计软件**，选择**连接 Paraşüt**。然后：

1. 向 Paraşüt 客服申请公司的 API 访问权限；他们会发送 client ID 和 client secret。
2. 公司编号在地址栏中 uygulama.parasut.com/ 之后。
3. 连同一位 Paraşüt 用户的邮箱和密码一起填写。密码只用一次来获取密钥，不会被保存。

## 限制与时间

Paraşüt 允许每 10 秒约 10 次请求，每页返回 25 行；它没有"自某时起变更"筛选，因此每次运行都完整读取列表。对小企业来说只是几十页。金额按发票币种读取（TRY、USD、EUR、GBP）。

## 出现问题时

如果 Paraşüt 不再接受连接（密钥或登录被撤销），该连接会在 设置 → 连接 中标记为"有问题"，并通知管理员一次；在其页面上选择**重新连接**。速率限制的回复不是错误：本次运行会停下、记住位置，下次继续。
