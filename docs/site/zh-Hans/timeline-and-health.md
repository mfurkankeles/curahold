# 时间线和健康评分

每个客户页面都有 **时间线**，如果你开启了，还有 **健康评分**。时间线讲述与客户之间发生了什么；评分把这些汇总成一个数字，并附上原因。

## 时间线

在顶部的输入框中选择 **备注**、**电话**、**会议** 或 **邮箱**，写下发生的事情并添加。需要的话可以修改日期，并勾选与你交谈过的人。

以下内容会自动出现在时间线上：

- 为该客户创建和完成的任务
- 这些任务上的评论
- 新增的联系人（关键干系人）
- 健康评分变动 10 分或以上的日子

把重要的备注 **置顶**，就能一直显示在最上方。条目的作者或负责管理客户的人可以编辑或删除它。你无法打开的看板上的任务，或对你隐藏的字段，也不会出现在时间线上。

## 计划中的会议

时间线记录的是已经发生的事。**计划中的会议** 是即将发生的事。在客户页面的 **即将举行的会议** 下选择 **安排会议**：选择类型（会议、回顾或电话，或你保存的某种类型），设定开始时间和时长，邀请双方人员，写好议程，并选择是否重复。会议会显示在客户页面和你的 **日历** 中，但还不会出现在时间线上——在会议举行之前不会记录任何内容。

每个计划中的会议都有自己的过程：

- 会议举行后点 **标记为已举行**。这会把会议记录到时间线上，议程作为备注，并把两者关联起来。如果是重复会议，下一次会自动安排好。你可以同时商定后续步骤，每一步都会成为一个任务。
- 填写原因后 **延期**。会议会保留，你可以把它改到另一天的同一时间。
- 填写原因后 **取消**。它会以“已取消”的状态留在记录中——不会删除任何内容。

**保存的类型。** 管理员可以为你们经常举行的会议命名（如季度业务回顾、每月例行沟通），并为每种会议设置议程提示。安排会议时选择类型会自动填好议程，让每次回顾都从同样的问题开始。

## 健康评分

在“设置”→ 健康评分 中开启。它是每个客户 0 到 100 之间的一个数字，根据 Curahold 中已有的信息计算得出：

| 信号 | 满分 | 零分 |
| --- | --- | --- |
| 最近接触 | 最近一次电话、会议、邮件或备注在 14 天内 | 45 天或更久 |
| 逾期工作 | 没有逾期任务 | 3 个或更多逾期任务 |
| 支持负担 | 没有未解决的支持工单 | 5 个未解决工单（紧急工单算两个） |
| 核心支持者 | 至少有一位“核心支持者”联系人 | 没有 |
| 已知决策人 | 至少有一位“决策人”联系人 | 没有 |
| 没有阻碍者 | 没有阻碍者或怀疑者 | 有阻碍者 |
| 负责人的判断 | 某个选项字段的第一个选项（例如“良好”） | 最后一个选项（例如“有风险”） |
| 数字字段 | 你设定的值 | 你设定的值 |

权重、天数和分级（健康、值得关注、有风险）都由你决定。保存前，预览会显示每个客户的得分。某个客户缺少数据的信号会被略过，由其他信号分摊它的权重。

> **为什么？** 在客户页面上评分旁边的 **为什么？** 会显示每个信号给出的分数，以及最近几周的图表。评分不是黑箱：每一分从哪里来都看得清清楚楚。

评分和任何客户字段一样使用：列表中的一列、筛选条件、主页卡片、导出、API 和 webhook。在 CRM 同步中把它映射到某个字段，它也会写入你的 CRM。任何人都不能手动输入它。

客户发生变化后几秒内会重新计算，每天也会计算一次。每天的评分都会保留；趋势和每周摘要就来自这些数据。

## 每周摘要

每周一，在你为早间摘要选择的时间，你会收到一份客户摘要：未来 30 天内的续约、下降的评分及主要原因、30 天以上没有接触的客户，以及本周的工作。可以在“你的设置”中关闭。
