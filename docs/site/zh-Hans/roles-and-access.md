# 角色和权限

角色决定谁能看到和修改什么。规则在数据库中强制执行，而不只是在界面上：屏幕上隐藏的内容，在 API、导出文件和 AI 连接器中同样隐藏。

## 席位

- **完整席位：** 可以查看和修改。
- **查看者席位：** 只能查看。适合经理和管理层。

## 内置角色：每个角色能看到和做什么

| 角色 | 简介 |
| --- | --- |
| 管理员 | 一切：公司设置、人员、角色、连接、活动日志 |
| 团队负责人 | 可以看到所有看板；管理团队、客户字段和自动化 |
| 成员 | 自己的工作以及能访问的客户 |
| 查看者 | 只看，不改 |

可以重命名角色、添加自己的角色，并逐项开启或关闭权限。

## 客户访问权限

为每个角色选择它能访问哪些客户：

- **所有客户**
- **本团队的客户：** 所在团队的客户，加上自己的客户
- **仅自己的客户**

客户下的联系人、商机和任务遵循同样的规则。

## 字段级权限

可以对某些角色隐藏某个字段，或者只允许查看不允许修改。例如，成员能看到“年度金额”但不能修改，只有管理员能看到“折扣”。

## 以他人视角查看

在“设置”→ 角色和权限 中，点人员旁边的 **以…的视角查看**，就会按照那个人看到的样子打开 Curahold。期间什么都不能修改，顶部的提示条可以带你回到自己的视图。
