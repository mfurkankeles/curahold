# 可接受使用政策

> **草稿——须经律师批准。** 版本 2026-11-19.draft2。服务条款的组成部分。本文是英文文本的译本，仅为方便阅读；如有任何不一致，以英文文本为准。

客户及其用户不得使用 Curahold：

1. 违反法律或侵犯他人权利，或存储、发送违法、侵权、诽谤或骚扰性内容；
2. 未经收件人许可发送垃圾信息或营销信息；
3. 上传恶意软件，或对服务进行探测、扫描、负载测试或攻击，或试图访问其他公司的数据或不属于自己的账号（安全研究仅限按"报告安全问题"页面进行）；
4. 多人共用一个席位，规避设备上限、席位数量或其他限制，或未经书面协议转售或再许可服务；
5. 复制或再现服务、其设计或内容，或对其进行反向工程、反编译或反汇编（强制性法律允许的除外）；
6. 未经我们书面许可，以自动化方式抓取、爬取或以其他方式访问服务、其页面或文档——允许使用客户自己的密钥在限制范围内通过已发布的 API 访问；
7. 使用 AI 代理、机器人或浏览器自动化探索、记录或提取服务的功能、界面、工作流程、内容或设计；
8. 构建或改进竞争性产品，或为此目的对服务进行基准测试或测试；
9. 对服务、文档或我们的网站进行文本与数据挖掘（权利保留——条款第 9 条）；
10. 存储**特殊类别个人信息**（健康、生物识别、宗教、犯罪记录等）、支付卡号或**儿童信息**，书面约定的除外；
11. 在受全面制裁的国家使用服务或为其中的人员使用服务，或为制裁名单上的任何人使用服务；
12. 秘密监控员工，或以法律禁止的方式使用活动功能——客户须事先告知员工，并将个人层面的视图限于需要的角色；
13. 使用 AI 功能生成违法内容、在没有人工决定的情况下对个人作出具有法律效力的决定，或以违反模型提供商使用规则的方式使用。

**合理使用。**API、自动化、导入、导出和 AI 功能设有限制，以确保服务对所有人都保持快速（在 API 参考中记载并在产品中显示）。远超正常使用的流量可能会被限速，或被要求转到合适的方案。超出限制的请求会收到"请求过多"的答复及等待时间；已知的爬虫和自动化工具可能会被直接拒绝。

**后果。**我们会尽可能先发出警告并要求纠正。违规严重或持续时，我们可以删除内容、在尽可能小的范围内限速或**暂停**访问；对严重或反复的违规，可以**终止**协议（条款第 13 条）。请将滥用行为报告至 [滥用举报邮箱]。
