# セキュリティとプライバシー

## 会社どうしは互いに見えません

すべての問い合わせは、データベースの行レベルのセキュリティのルールのもとで実行されます。ある会社のデータを、別の会社のアドレス、API、コネクタから読む方法はありません。ロールと項目のルールも同じ層で強制されます。

## セッションと端末

セッションは端末に結びついていて、コピーした Cookie は別の端末では使えません。端末の上限を超えると、いちばん古いセッションがログアウトされます。あなたの設定 → 端末 でセッションを確認し、終了できます。

## パスキーと 2 段階目

メールのリンクに加えて、**パスキー**（指紋、顔、端末の PIN）でログインでき、**2 段階目** として認証アプリを追加できます。スマートフォンをなくしたとき用に、1 回限りの回復コードが 10 個付きます。設定は **自分の端末 → ログインのセキュリティ** で行い、ここでほかのすべての端末から一度にログアウトすることもできます。管理者は **設定 → ログイン** で、2 段階目を管理者だけ、または全員に必須にでき、ログインのたびにサーバーで確認されます。シングルサインオンでログインする人には改めて求めません。ID プロバイダーが行うからです。締め出される人はいません：管理者は誰の 2 段階目でもリセットでき、自社サーバーへのインストールにはサーバーの環境変数（`RESET_SECOND_STEP`）でのリセットがあります。

ロール、シングルサインオン、SCIM の変更、API キーの作成、個人データのエクスポートや削除、メンバーの削除、アクティビティログのエクスポートでは、ログインから 10 分以上たっていると **ご本人確認**（パスキー、アプリのコード、またはメールのコード）を求めます。

## 端末に保存されるもの

オフラインでも読めるように、アプリは最後に見た一覧のコピーをブラウザー自身の保存領域に保持します（タスク、ボード、顧客、受信トレイ。添付ファイルと設定は含みません）。コピーはその端末のそのブラウザーにだけあり、どこにも送られません。ログアウトしたとき、またはサーバー側でセッションが終了した後の最初の接続で削除されます。共用のパソコンでは、使い終わったらログアウトしてください。

## アクティビティログ

ログイン、2 段階目、メンバーとロールの変更、連携、API キー、Webhook、個人データの操作は、設定 → アクティビティログ に記録されます。ログは追記だけができ、変更や削除はできません。アプリが使うデータベースのロールからもできません。**ログをエクスポート** すると、連続した SHA-256 のフィンガープリント付きでダウンロードされ、最後のフィンガープリントもログに記録されるので、あとからコピーを検証できます。

## カスタマーポータル

カスタマーポータルは、専用のセッションと Cookie を持つ別のドメインで動いています。ポータルのリクエストに使われるデータベースのロールは、どのテーブルにも権限がなく、ログインしている人の自社の共有データを返す関数を呼べるだけです。詳しくは [カスタマーポータル](/docs/ja/customer-portal/)。

## Curahold サポートのアクセス

Curahold のサポートが会社に入るのは、その会社の人の同意があるときだけです：サポートへの依頼でチェックを入れ、期間（24 時間～7 日）を選びます。サポートに見えるのはその人に見えるものと同じで、見るだけです。何かを変えることは決してありません。アクセスは選んだ期間が過ぎると終わり、いつでも閉じられます。サポートの訪問と、その間に読んだものは、担当者の名前とともにアクティビティログに記録されます。管理者は **設定 → セキュリティ → サポートのアクセス** で、これを管理者だけに限るか、オフにできます。詳しくは [サポートを受ける](/docs/ja/getting-help/)。

## 個人データ

設定 → メンバー で、その人のメニューから次の操作ができます：

- **データをダウンロード：** その人に関するすべてをひとつのファイルで。
- **個人データを削除：** 名前とメールが消え、その人が行った作業は匿名で残ります。先に担当顧客と未完了のタスクをほかの人に引き継いでください。

## 保存期間

| データ | 保存期間 |
| --- | --- |
| 通知 | 90 日 |
| 終了したセッション | 90 日 |
| 同期の履歴 | 90 日 |
| [ごみ箱](/docs/ja/trash/) にある、削除した顧客、レコード、タスクなど | 30 日。その後ファイルとともに消去。管理者はそれより早く消去できます |
| インポートを取り消すためのデータ | 30 日 |
| Webhook の配信記録 | 7 日 |
| エラーの記録（どこで何が壊れたか。リクエストの内容は含みません） | 30 日 |
| 無効にした API キー | 30 日 |

## 保存している秘密情報

CRM やチャットとの連携の認証情報と、Webhook の署名用シークレットは、暗号化して保存します。API キーはダイジェストだけを保持し、キーそのものは一度だけ表示され、二度と見ることはできません。
