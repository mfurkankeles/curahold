# ごみ箱

Curahold で削除しても、すぐには消えません。ごみ箱に移って 30 日間残り、元のとおりに戻せます。30 日が過ぎると、ファイルも含めて完全に消去されます。

## ごみ箱に入るもの

| 削除するもの | 一緒に入るもの | 残るもの |
| --- | --- | --- |
| 顧客 | レコード（連絡先、商談など）、タイムライン、ミーティング、ヘルスの履歴、ポータルの利用者 | タスクは顧客なしでボードに残ります |
| タスク | サブタスク、コメント、時間、フォロワー、リンク、ファイル | ほかには何も触れません |
| レコード | コメントとファイル | そのレコードを指していたタスク |
| タイムラインの記録やミーティング | それ自体だけ | ミーティングの次のステップはタスクとして残ります |
| ページ、保存したレポート、自動化 | それ自体だけ | 自動化がすでに開いたタスク |

インポートを取り消すと、そのインポートで追加されたものがすべて、ひとつの項目としてごみ箱に入ります。

いくつかのものはごみ箱を通らずにすぐ削除されます：1 件のコメント、1 つのファイル、時間の記録、保存したビュー、Webhook、API キー。

## 元に戻す

削除した直後は、画面下の通知に **元に戻す** が表示されます。あとから戻すときは、メニュー（左下）から **ごみ箱** を開き、項目を探して **元に戻す** を選びます。

元のとおりに戻ります：同じアドレスに、一緒に移ったものすべてとともに。ほかのものからのつながりも結び直されます：顧客のタスクは再びその顧客を指します（その間に誰かがタスクを別の顧客に付け替えていない限り）。CRM と連携していれば、同期も再び追いかけます。誰にも通知は届かず、Webhook も送られません。戻ることはニュースではないからです。

戻らないものが 3 つあります：すでに送られた通知と、顧客のポータル利用者の開いていたセッションと 1 回限りのリンクです。利用者はもう一度ログインします。受け入れられていなかった招待は送り直す必要があります。

### まだ戻せないとき

- **属していたものもごみ箱にある。** レコードには顧客が、サブタスクには親タスクが必要です。Curahold がどれかを伝えるので、先にそちらを戻してください。
- **属していたものがもう存在しない。** たとえばレコードの種類が削除された場合。戻せません。
- **別のものがその場所を使っている。** 別の顧客が同じ CRM の ID を持っている、またはポータルの利用者が同じメールを使っている場合。先にそちらを変更または削除してください。

その下にあるものの一部が属する先を完全に失っていても、残りは戻り、外れた件数がメッセージで示されます。

## 誰に何が見えるか

- 自分で削除したものは、自分で見て戻せます。
- 会社の設定を変更できる人、またはプライバシーを管理できる人は、会社で削除されたものをすべて見て、どれでも戻せます。
- 閲覧席の人は削除できないので、ごみ箱はありません。

## 完全に削除する

会社の設定を変更できる人、またはプライバシーを管理できる人は、どの項目にも **完全に削除** を選べます。ファイルとともにすぐに消去され、誰も元に戻せません。30 日待てない個人データの削除依頼に使います。

それ以外のものは、30 日が過ぎると自動で消えます。

## 開発者向け

ごみ箱に移す `DELETE` はすべて `trashId` を返します。一覧、元に戻す、完全に削除は [ごみ箱のリファレンス](/docs/ja/ref-trash/) にあります。
