# 通知

Curahold はまずチャットアプリに送り、届かないときはメールを使います。通知はチームがふだん見ている場所に届きます。

## 通知が届くとき

- タスクが自分に割り当てられたとき
- コメントでメンションされたとき
- 自分が関わるタスクにコメントがあったとき
- 自動化が自分の作業を開いたとき
- 朝のまとめ：今日の作業と遅れているもの
- 月曜の週次まとめ：更新と、スコアが下がった顧客や連絡が途絶えた顧客
- 木曜のリマインド：長い間誰も触れていない、自分の未完了タスク
- チームリードには：期限を数日過ぎたチームのタスク

それぞれ、あなたの設定でオン・オフできます。

## リマインド

2 種類あり、どちらも 設定 → **目標とサイクル** でオンにして調整します。

- **止まっている作業**（既定：14 日、オン）。毎週木曜、朝のまとめの時刻に、その期間誰も触れていない自分の未完了タスクの一覧が届きます。先の予定の作業（まだ来ていない開始日、または 1 週間以上先の期日）とミュートしたタスクは除かれます。
- **遅れた作業をチームリードへ**（既定：オフ）。タスクが設定した日数だけ期日を過ぎると、担当者のチームリードにその営業日に一度だけ知らせます。担当者のいない作業やリードのいないチームでは、ボードを作った人に知らせます。週末に期限を越えたものは月曜に知らせます。オンにしても、過去にたまったものをまとめて送ることはありません。全体像はチームのページにあります。

どちらも、あなたの設定の「リマインド」で自分だけオフにできます。

## 届け先

会社が Slack、Microsoft Teams、Google Chat を接続していれば、通知はそこにダイレクトメッセージで届きます。そうでなければメールで届きます。

## 通知を控える時間帯

たとえば 19:00～08:30 のように設定します。その時間帯の通知は保留され、時間帯が終わると送られます。時間は会社のタイムゾーンに従います。

## カレンダー連携

あなたの設定 → カレンダー で個人用のカレンダーのアドレスを作り、Google カレンダー、Outlook、Apple カレンダーに追加します。期日のあるタスクがカレンダーに表示されます。古いアドレスを無効にするには、新しいアドレスを作ります。

## スタートプランのリマインダー

スタートプランで自分の番になったときや、自分のステップが止まったときは、アプリでお知らせします。メールでも受け取るには、**通知を受け取る内容**で**スタートプランのリマインダーをメールでも受け取る**をオンにします。オンにするまではオフです。通知を控える時間帯と朝のまとめが適用されます。
