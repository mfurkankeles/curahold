# Odoo（会計）

Odoo Online、Odoo.sh、自社サーバーの Odoo から顧客、請求書、入金。

## 読み込む内容

顧客（ソフトにあれば税番号、メール、ウェブアドレスも）、期日と未回収額付きの請求書、受け取った入金です。Curahold は Odoo に一切書き込みません。作成・変更・削除はできません。

## 連携の手順

**設定 → データソース**の**会計ソフト**で **Odoo を連携** を選びます。そのあと：

1. Odoo でプロフィール → 個人設定 → アカウントセキュリティを開き、API キーを作成します。
2. Odoo のアドレスとログイン名を控えます。Odoo.sh や自社サーバーならデータベース名も。
3. 下に入力します。Odoo Online では API の利用に Custom プランが必要です（Odoo の規定）。

## 制限とタイミング

Odoo は固定の上限を公表していません。小さなサーバーに負担をかけないよう、Curahold は 1 秒あたり約 2 リクエストに抑えます。Odoo 19 以降は JSON-2 API で、それより前は JSON-RPC で読みます（その場合はデータベース名が必要です）。変更は 1 時間ごとに読みます。

## うまくいかないとき

Odoo が連携を受け付けなくなったとき（キーやログインの取り消し）、設定 → 連携 でその連携に「問題あり」が付き、管理者に一度だけ知らせます。連携のページで**再接続**を選んでください。リクエスト上限の応答はエラーではありません。実行は止まって位置を覚え、次回続きから読みます。
