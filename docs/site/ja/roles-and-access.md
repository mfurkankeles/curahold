# ロールと権限

ロールで、誰が何を見て何を変えられるかが決まります。ルールは画面だけでなくデータベースで強制されます。画面で隠れているものは、API、エクスポート、AI コネクタからも隠れています。

## 席

- **フル席：** 見ることも変えることもできます。
- **閲覧席：** 見るだけです。マネージャーや経営層に向いています。

## 用意されたロール：それぞれが見られること、できること

| ロール | ひとことで |
| --- | --- |
| 管理者 | すべて：会社の設定、メンバー、ロール、連携、アクティビティログ |
| チームリード | すべてのボードを見られ、チーム、顧客の項目、自動化を管理 |
| メンバー | 自分の仕事と、アクセスできる顧客 |
| 閲覧者 | 見るだけで、変更はしない |

ロールの名前を変えたり、独自のロールを追加したり、権限をひとつずつオン・オフしたりできます。

## 顧客へのアクセス

ロールごとに、アクセスできる顧客を選びます：

- **すべての顧客**
- **自分のチームの顧客：** 所属するチームの顧客と、自分の顧客
- **自分の顧客だけ**

顧客の下の連絡先、商談、タスクも同じルールに従います。

## 項目ごとの権限

一部のロールから項目を隠したり、見せても変えられないようにしたりできます。たとえば、メンバーは「年間契約額」を見られても変えられず、「値引き」は管理者しか見られない、といった設定です。

## …の視点で見る

設定 → ロールと権限 で、メンバーの横の **…の視点で見る** を使うと、その人に見えるとおりの Curahold が開きます。その間は何も変更できず、上部の帯から自分の表示に戻れます。
