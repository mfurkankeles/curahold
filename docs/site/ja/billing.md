# プランと請求

## 無料トライアル

新しい会社は **14 日間**、カードなしですべての機能を使えます。設定 → **請求** に残りの日数が表示され、最後の 1 週間はアプリ上部の 1 行でもお知らせします。

## プラン

| | Team | Business |
| --- | --- | --- |
| ボード、タスク、チェックリスト、自動化 | ✓ | ✓ |
| 顧客、連絡先、商談、独自のレコード | ✓ | ✓ |
| ミーティング、タイムライン、ヘルススコア、ビジネスレビュー | ✓ | ✓ |
| レポート、ダッシュボード、目標 | ✓ | ✓ |
| Slack、Teams、Google Chat、メールでの通知 | ✓ | ✓ |
| CRM やスプレッドシートとの双方向同期 | | ✓ |
| カスタマーポータル | | ✓ |
| プレイブックと、自動で始まる更新 | | ✓ |

料金は **フル席** ひとつあたりの月額で、現地価格がある地域ではその通貨（インド・ルピー、シンガポール・ドル、トルコ・リラ）、それ以外では米ドルで表示され、年払いならお得になります。該当する場合は税金（VAT、GST、SST など）がお支払い時に加算され、Paddle が徴収・納付します。**閲覧席は無料です。**

## プランを選ぶ

管理者が 設定 → **請求** を開き、月払いか年払いかを選んで **Team を選ぶ** または **Business を選ぶ** を押します。お支払いのページ（販売代理店の Paddle）がアプリの上に開き、完了すると数秒でプランがページに表示されます。

## 席

請求は、フル席で **参加した** 人に合わせて行われます。まだ受け入れられていない招待は請求されません。人を追加すると追加の席は期間の残りについて請求され、人を外すと次回の請求が下がります。席数を手で変える必要はありません。どのプランも最低数席分のフルシートで請求されます（通常は 3 席。地域や年払いではそれより多いことがあります）。設定 → **請求** に地域ごとの席数が表示され、その人数までは追加料金はかかりません。

## 請求書、支払い方法、解約

請求のページの **請求書、支払い、解約** から、ログイン済みの Paddle のカスタマーポータルが開きます：請求書のダウンロード、カードの変更、解約ができます。解約したプランは、支払い済みの期間の終わりまで使えます。

Team と Business の切り替え、月払いと年払いの切り替えも同じページで行い、差額は期間の残りについて請求（または返金）されます。

## 各プランの上限

料金を低く保つため、各プランには運用コストがかかるものにいくつか上限があります。設定 → **請求** に、ご利用のプランの数値とそれぞれの使用量が表示されます：

| 上限 | 上限に達したとき |
| --- | --- |
| フル席 | 新しいメンバーは閲覧者（無料）として参加できます。フル席を増やすには上位のプランを選んでください。 |
| 連携ツール（CRM、スプレッドシート、サポート・会計ツール） | 新しいツールを連携するとき、いずれかを解除するか上位のプランを選ぶよう案内されます。連携済みのツールへの再ログインはいつでもできます。 |
| 連携ツールの同期間隔 | プランごとの間隔で同期します（Business では 1 時間ごと）。**今すぐ同期** はいつでも使えます。 |
| ファイル容量（フル席ごと、会社で共有） | 古いファイルを削除するか上位のプランを選ぶまで、新しいアップロードはできません。何も削除されません。 |
| 月ごとの CuraAI 回答（フル席ごと、共有） | 翌月まで、CuraAI はモデルではなくヘルプページから回答します。 |

トライアル中はすべて使えます。CuraAI の月ごとの回答数だけが少なめです。

## プランがないとき

プランを選ばずにトライアルが終わったときや、解約したプランの期間が終わったときも、何も削除されません。全員がすべてを **閲覧とエクスポート** でき、管理者がプランを選ぶまで変更はできません。プランを選べば、止まったところから作業を続けられます。

支払いに失敗しても、Paddle が再試行する間、最初の失敗から最長 30 日間はすべて使えます。上部の 1 行で、管理者に支払い方法の更新をお願いします。その後は、支払いが完了するまでプランがないときと同じく閲覧のみになります。

## 自社サーバー

自社サーバーにインストールした Curahold には請求がなく、すべての機能が使えます。
