# プランと請求

## 無料トライアル

新しい会社は **14 日間**、カードなしですべての機能を使えます。設定 → **請求** に残りの日数が表示され、最後の 1 週間はアプリ上部の 1 行でもお知らせします。

## プラン

| | Team | Business |
| --- | --- | --- |
| ボード、タスク、チェックリスト、自動化 | ✓ | ✓ |
| 顧客、連絡先、商談、独自のレコード | ✓ | ✓ |
| ミーティング、タイムライン、ヘルススコア、ビジネスレビュー | ✓ | ✓ |
| レポート、ダッシュボード、目標 | ✓ | ✓ |
| Slack、Teams、Google Chat、メールでの通知 | ✓ | ✓ |
| CRM やスプレッドシートとの双方向同期 | | ✓ |
| カスタマーポータル | | ✓ |
| プレイブックと、自動で始まる更新 | | ✓ |

料金は **フル席** ひとつあたりの月額（米ドル）で、年払いならお得になります。税金はお支払い時に加算されます。**閲覧席は無料です。**

## プランを選ぶ

管理者が 設定 → **請求** を開き、月払いか年払いかを選んで **Team を選ぶ** または **Business を選ぶ** を押します。お支払いのページ（販売代理店の Paddle）がアプリの上に開き、完了すると数秒でプランがページに表示されます。

## 席

請求は、フル席で **参加した** 人に合わせて行われます。まだ受け入れられていない招待は請求されません。人を追加すると追加の席は期間の残りについて請求され、人を外すと次回の請求が下がります。席数を手で変える必要はありません。

## 請求書、支払い方法、解約

請求のページの **請求書、支払い、解約** から、ログイン済みの Paddle のカスタマーポータルが開きます：請求書のダウンロード、カードの変更、解約ができます。解約したプランは、支払い済みの期間の終わりまで使えます。

Team と Business の切り替え、月払いと年払いの切り替えも同じページで行い、差額は期間の残りについて請求（または返金）されます。

## プランがないとき

プランを選ばずにトライアルが終わったときや、解約したプランの期間が終わったときも、何も削除されません。全員がすべてを **閲覧とエクスポート** でき、管理者がプランを選ぶまで変更はできません。プランを選べば、止まったところから作業を続けられます。

支払いに失敗しても、Paddle が再試行する間はすべて使えます。上部の 1 行で、管理者に支払い方法の更新をお願いします。

## 自社サーバー

自社サーバーにインストールした Curahold には請求がなく、すべての機能が使えます。
