# freee（会計）

freee会計の取引先と収入の取引。

## 読み込む内容

顧客（ソフトにあれば税番号、メール、ウェブアドレスも）、期日と未回収額付きの請求書、受け取った入金です。Curahold は freee に一切書き込みません。作成・変更・削除はできません。

## 連携の手順

**設定 → データソース**の**会計ソフト**で **freee を連携** を選びます。そのあと：

1. freee にログインし、連携する事業所を選びます。
2. アクセスを許可します。Curahold が読むのは取引先と収入の取引だけです。
3. ここに戻ったら最初の読み込みを始め、照合できなかった顧客を確認します。

## 制限とタイミング

Curahold は 1 秒に 1 リクエスト未満に抑えます。取引先は毎回すべて読みます（freee には取引先の更新日での絞り込みがありません）。前回の実行日以降に更新された取引は読み直します。金額は円です。

## うまくいかないとき

freee が連携を受け付けなくなったとき（キーやログインの取り消し）、設定 → 連携 でその連携に「問題あり」が付き、管理者に一度だけ知らせます。連携のページで**再接続**を選んでください。リクエスト上限の応答はエラーではありません。実行は止まって位置を覚え、次回続きから読みます。
