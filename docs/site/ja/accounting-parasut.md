# Paraşüt（会計）

Paraşüt の顧客、売上請求書、入金。

## 読み込む内容

顧客（ソフトにあれば税番号、メール、ウェブアドレスも）、期日と未回収額付きの請求書、受け取った入金です。Curahold は Paraşüt に一切書き込みません。作成・変更・削除はできません。

## 連携の手順

**設定 → データソース**の**会計ソフト**で **Paraşüt を連携** を選びます。そのあと：

1. Paraşüt のサポートに会社の API 利用を申し込みます。client ID と client secret が届きます。
2. 会社番号はアドレスバーの uygulama.parasut.com/ の後ろの数字です。
3. Paraşüt ユーザーのメールアドレスとパスワードと一緒に入力します。パスワードはキーを得るために一度だけ使い、保存しません。

## 制限とタイミング

Paraşüt は 10 秒あたり約 10 リクエストまでで、1 ページ 25 行を返します。更新日での絞り込みがないため、毎回の実行で一覧をすべて読みます。小さな会社なら数十ページです。金額は請求書の通貨（TRY、USD、EUR、GBP）で読みます。

## うまくいかないとき

Paraşüt が連携を受け付けなくなったとき（キーやログインの取り消し）、設定 → 連携 でその連携に「問題あり」が付き、管理者に一度だけ知らせます。連携のページで**再接続**を選んでください。リクエスト上限の応答はエラーではありません。実行は止まって位置を覚え、次回続きから読みます。
