# Claude と ChatGPT をつなぐ

Curahold を Claude、ChatGPT、または MCP に対応したアシスタントとつなぐと、アシスタントがあなたとして Curahold で調べものをし、作業を進められます。

## 頼めること

- 「今後 60 日以内に更新を迎える担当顧客のうち、リスクがありそうなのは？」
- 「ハーバーライン銀行のステークホルダーと未完了の作業をまとめて。」
- 「担当ポートフォリオの 5 枚のサマリー資料を作って。」
- 「山本さんに、ヴェルト・モビリティの利用減少を調べるタスクを明日期限で作って。」
- 「このタスクを完了にして『提案書を送付済み』とコメントして。」

## つなぎ方

1. Curahold で **あなたの設定** を開き、**コネクタのアドレス** をコピーします。`https://yourcompany.curahold.com/mcp` のような形です。
2. **Claude：** 設定 → コネクタ → カスタムコネクタを追加。アドレスを貼り付けて接続します。
   **ChatGPT：** コネクタの設定で、そのアドレスのカスタム（MCP）コネクタを追加します。プランによっては、先に開発者モードをオンにする必要があります。
3. Curahold の許可画面が開きます。ログインし、アシスタントに許可する内容を確認して **許可** を選びます。

## 安全性

- アシスタントは **あなたとして** 動きます。あなたが見られるものだけを見て、あなたが変えられるものだけを変えます。ロールと項目のルールはそのまま適用されます。
- 許可画面で「変更も許可する」のチェックを外すと、アシスタントは読むだけになります。閲覧席では、もともと読むだけです。
- あなたの設定 → API キーと接続済みアプリ で、いつでも接続を解除できます。
- アシスタントはあなた自身の Claude や ChatGPT のプランで動きます。Curahold が AI の料金を別途いただくことはありません。
