# クイック追加とショートカット

**N** を押すと（または左の **+ 新規 → タスク**、列の下の **タスクを追加**、スマートフォンでは下の **+**）、**新しいタスク** のウィンドウが開きます。件名の下で詳細を入力します：説明、顧客、属するレコード（商談、契約など）、担当者、期日、優先度、繰り返し、ボードと列、ボード独自の項目。列から開いた場合はその列が、顧客のページから開いた場合はその顧客が、最初から選ばれています。

項目をひとつずつ埋める必要はありません。思いついたとおりに件名を書けば十分です：

> 更新の打ち合わせ friday @山本 #ヴェルト !high

この 1 行で項目が埋まります：担当者は山本さん、顧客はヴェルト・モビリティ、期日は金曜日、優先度は高。件名から入った項目には **タイトルから** と表示されます。項目を手で変えると、その語は件名から外れ、項目は選んだ内容を保ちます。**Enter** でタスクを追加し、ほかの項目にいるときは **Ctrl Enter**（Mac では ⌘ Enter）です。

## 書けること

日付、繰り返し、優先度の語は、トルコ語以外のすべての言語で英語で書きます。

| 内容 | 書き方 | 例 |
| --- | --- | --- |
| 期日 | ふだんの言葉 | today、tomorrow、friday、next week、end of month、nov 15、15.11、in 3 days |
| 担当者 | @ と名前 | @山本、@小林 大輔、@me |
| 顧客 | # と名前 | #ヴェルト、#ハーバーライン銀行 |
| 優先度 | ! とレベル | !urgent、!high、!low |
| 繰り返し | every … | every day、every week、every monday、every 2 weeks、monthly |

日本語の文章では、@ や # の語の前後に半角スペースを入れてください。

- **@** や **#** を入力すると一覧が開きます。矢印キーで選び、**Enter** か **Tab** で決めます。
- ラベルの **×**：担当者、顧客、優先度を行から外します。日付や繰り返しとして読まれた語は件名に残ります（引用符付き）。日付として読ませたくない語は、自分で引用符で囲んでください："may" campaign report
- 誰にも一致しない @ や # は黄色い枠で表示され、件名に残ります。

## どこで追加するかで変わること

- **自分のタスク** から追加すると、自分のタスクになります。
- **ボード** では、ボードの最初の列に入ります。ボードと列はウィンドウの下で変えられます。
- **顧客のページ** では、その顧客に紐づきます。
- **カレンダー** では、日付の **+** でその日のタスクになります。

## まとめて何件でも

数行を貼り付けると（ミーティングのメモなどから）、1 行ずつ別のタスクになり、追加する前にすべて表示されます。**Ctrl Enter**（Mac では **⌘ Enter**）ですべて追加します。「続けて追加」にチェックすると、ウィンドウは開いたままです。

## ワンクリックで完了

一覧やカードでは、各タスクの前に丸いチェックがあります。クリックするとタスクはボードの「完了」の列に移ります。間違えたら、表示される通知で **元に戻す**。タスクのウィンドウの **完了にする** ボタンも同じです。

## キーボードショートカット

入力欄に入力している間を除き、どこでも使えます。アプリの中でも **?** でこの一覧が表示されます。

| キー | 動作 |
| --- | --- |
| N | 新しいタスク |
| Ctrl K または / | 検索して移動 |
| ? | ショートカット |
| Esc | 開いているものを閉じる |
| G → H | ホーム |
| G → M | 自分のタスク |
| G → C | カレンダー |
| G → A | 顧客 |
| G → P | プロフィール |
| G → S | 設定 |

## スマートフォンでは

下に 5 つのボタンがあります：ホーム、自分のタスク、中央の **+**、顧客、カレンダー。ボード、設定、メニューは左上の ☰ の中です。

## 外観

メニュー（左下の自分の名前）で **ライト**、**ダーク**、**この端末の設定に合わせる** を選びます。選択はその端末に保存されます。
