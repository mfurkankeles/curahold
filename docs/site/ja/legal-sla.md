# サービスレベル契約（SLA）

> **草案 — 弁護士の承認が必要です。** バージョン 2026-11-19.draft1。有料プランに適用される利用規約の一部です（トライアルには適用されません）。[角かっこ] 内の数値は提案です。当社の監視で証明できる数値のみを約束します。本書は英語版を読みやすくするための翻訳であり、両者に相違がある場合は英語版が優先します。

## 1. 可用性

- **目標：**各暦月の **[99.5]%** の時間、本サービスを利用できること。
- **測定：**少なくとも 2 つのリージョンから、ログインページと API を毎分外部からチェックします。両方のリージョンで失敗した分を利用不可とします。数値はステータスページ [ステータスページの URL] に表示します。
- **算入しないもの：**少なくとも 48 時間前に告知した計画メンテナンス（月 [4] 時間まで、可能な限りイスタンブール時間 08:00〜20:00 以外）、顧客、そのネットワークまたは接続した第三者のツールに起因する問題、利用規約に基づく停止、不可抗力、ベータと表示された機能。

## 2. サービスクレジット

| 月間可用性 | クレジット（当月料金に対する割合） |
| --- | --- |
| [99.5]% 未満 | [10]% |
| [99.0]% 未満 | [25]% |
| [95.0]% 未満 | [50]% |

管理者は、月末から 30 日以内にサポートを通じてクレジットを請求します。クレジットは次回の請求書から差し引かれ、現金では支払われず、可用性が達成されない場合の**唯一の救済**です。任意の 6 か月のうち 3 か月で可用性が [99.0]% を下回った場合、顧客は契約を終了し、前払料金の返金を受けることができます。

## 3. サポート

| 重大度 | 例 | 初回応答 |
| --- | --- | --- |
| 1 — 緊急 | 本サービスが停止している、またはデータが危険にさらされている | [4] 営業時間 |
| 2 — 重大 | 主要機能が動作せず、回避策がない | [1] 営業日 |
| 3 — 軽微 | 機能が動作しないが、回避策がある | [2] 営業日 |
| 4 — 質問 | 使い方、要望 | [3] 営業日 |

営業時間：[イスタンブール時間 月〜金 09:00〜18:00、トルコの祝日を除く]。窓口：アプリ内のヘルプと [サポート用メールアドレス]。

## 4. バックアップと復旧

- 少なくとも毎日バックアップし、35 日間保存します。
- **目標復旧時点（RPO）：**[24] 時間。**目標復旧時間（RTO）：**[8] 時間。
- 少なくとも四半期ごとに復元テストを行います [ホスティング構成と要確認]。

## 5. 変更

本 SLA は利用規約第 19 条に定めるとおり変更されます。有料のサブスクリプション期間中に目標を引き下げる変更は行いません。
