# الخطط والفوترة

## التجربة المجانية

تستطيع الشركة الجديدة استخدام كل شيء **14 يومًا** دون بطاقة. تعرض الإعدادات ← **الفوترة** كم يومًا تبقى، وفي الأسبوع الأخير يقول ذلك أيضًا سطر أعلى التطبيق.

## الخطط

| | Team | Business |
| --- | --- | --- |
| اللوحات والمهام وقوائم التحقق والأتمتة | ✓ | ✓ |
| العملاء وجهات الاتصال والفرص وسجلاتك الخاصة | ✓ | ✓ |
| الاجتماعات والمخطط الزمني ومؤشر الصحة ومراجعات الأعمال | ✓ | ✓ |
| التقارير ولوحات المعلومات والأهداف | ✓ | ✓ |
| إشعارات Slack وTeams وGoogle Chat والبريد الإلكتروني | ✓ | ✓ |
| مزامنة باتجاهين مع CRM أو جدول بيانات | | ✓ |
| بوابة العملاء | | ✓ |
| كتيبات العمل، والتجديدات التي تبدأ وحدها | | ✓ |

الأسعار لكل **مقعد كامل** شهريًا، بعملة منطقتك حيث لدينا سعر محلي (الروبية الهندية، الدولار السنغافوري، الليرة التركية) وبالدولار الأمريكي في غيرها، وأقل عند الدفع السنوي. تُضاف الضريبة (ضريبة القيمة المضافة وما يماثلها) عند الدفع حيثما تنطبق؛ تحصّلها Paddle وتؤديها. **مقاعد المشاهدة مجانية.**

## اختيار خطة

يفتح المسؤول الإعدادات ← **الفوترة**، ويختار شهريًا أو سنويًا، ويضغط **اختر Team** أو **اختر Business**. تفتح صفحة الدفع (Paddle، الموزّع لدينا) فوق التطبيق، وعند الانتهاء تظهر الخطة في الصفحة خلال ثوانٍ.

## المقاعد

تتبع الفاتورة الأشخاص الذين **انضموا** بمقعد كامل: الدعوة التي لم تُقبل بعد لا تُفوتر. أضف شخصًا فيُفوتر المقعد الإضافي لبقية الفترة، واحذف شخصًا فتنخفض الفاتورة التالية. لا يحتاج أحد إلى تغيير عدد المقاعد يدويًا.

## الفواتير وطريقة الدفع والإلغاء

يفتح **الفواتير والدفع والإلغاء** في صفحة الفوترة بوابة عملاء Paddle وأنت مسجّل الدخول: نزّل الفواتير، وغيّر البطاقة، وألغِ. وتبقى الخطة الملغاة عاملة حتى نهاية الفترة المدفوعة.

والانتقال بين Team وBusiness، أو بين الشهري والسنوي، في الصفحة نفسها؛ ويُفوتر الفرق (أو يُعاد) لبقية الفترة.

## حدود كل خطة

تضع كل خطة حدودًا قليلة على ما يكلّفنا تشغيله، كي يبقى السعر منخفضًا. تعرض الإعدادات ← **الفوترة** أرقام خطتك ومقدار ما تستخدمه من كل منها:

| الحد | ماذا يحدث عند بلوغه |
| --- | --- |
| المقاعد الكاملة | يمكن للأشخاص الجدد الانضمام كمشاهدين (مجانًا)؛ ولمزيد من المقاعد الكاملة اختر خطة أكبر. |
| الأدوات المتصلة (أنظمة إدارة العملاء، جداول البيانات، أدوات الدعم والمحاسبة) | عند ربط أداة جديدة يُطلب منك إزالة واحدة أو اختيار خطة أكبر. إعادة تسجيل الدخول إلى أداة متصلة ممكنة دائمًا. |
| عدد مرات مزامنة الأدوات المتصلة | لكل خطة جدولها (كل ساعة في Business)؛ وزر **زامن الآن** متاح دائمًا. |
| مساحة الملفات (لكل مقعد كامل، مشتركة في الشركة) | يتوقف رفع الملفات الجديدة حتى تُحذف ملفات قديمة أو تختار خطة أكبر. لا يُحذف شيء. |
| إجابات CuraAI شهريًا (لكل مقعد كامل، مشتركة) | يجيب CuraAI من صفحات المساعدة بدل النموذج حتى الشهر التالي. |

خلال التجربة كل شيء متاح؛ فقط لـ CuraAI حصة شهرية أقل.

## دون خطة

عندما تنتهي التجربة دون خطة، أو تنقضي خطة ملغاة، لا يُحذف شيء. يستطيع الجميع **القراءة والتصدير** لكل شيء، ولا يمكن تغيير شيء حتى يختار المسؤول خطة، ثم يستمر العمل من حيث توقف.

وإذا فشل دفع، يستمر كل شيء في العمل بينما يعيد Paddle المحاولة، لمدة تصل إلى 30 يومًا من أول دفعة فاشلة؛ ويطلب السطر في الأعلى من المسؤول تحديث طريقة الدفع. بعد ذلك تصبح الشركة للقراءة فقط، كما لو لم تكن هناك خطة، حتى تنجح دفعة.

## خادمك الخاص

لا فوترة في Curahold المثبّت على خادمك الخاص: كل شيء مفتوح.
