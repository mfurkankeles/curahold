# سياسة الاستخدام المقبول

> **مسودة — تتطلب موافقة المحامي.** الإصدار ⁦2026-11-21.draft3⁩. جزء من شروط الخدمة. هذه ترجمة للنص الإنجليزي لتيسير القراءة؛ وعند أي اختلاف يسود النص الإنجليزي.

لا يجوز للعميل ومستخدميه استخدام Curahold من أجل:

1. مخالفة القانون أو حقوق أي شخص، أو تخزين محتوى غير مشروع أو منتهك أو تشهيري أو مسيء أو إرساله؛
2. إرسال رسائل مزعجة أو رسائل تسويقية دون إذن المتلقين؛
3. رفع برمجيات خبيثة، أو سبر الخدمة أو مسحها أو اختبار تحمّلها أو مهاجمتها، أو محاولة الوصول إلى بيانات شركة أخرى أو إلى حساب ليس لهم (البحث الأمني مسموح فقط وفق صفحة الإبلاغ عن مشكلة أمنية)؛
4. مشاركة مقعد بين عدة أشخاص، أو الالتفاف على حد الأجهزة أو أعداد المقاعد أو حدود أخرى، أو إعادة بيع الخدمة أو ترخيصها من الباطن دون اتفاق مكتوب؛
5. نسخ الخدمة أو تصميمها أو محتواها أو استنساخها، أو إجراء الهندسة العكسية لها أو تفكيكها أو إعادة تجميعها (إلا حيث يسمح القانون الآمر)؛
6. كشط الخدمة أو صفحاتها أو الوثائق أو الزحف عليها أو الوصول إليها بوسائل آلية بأي طريقة أخرى دون إذن كتابي منا — ويُسمح بواجهة API المنشورة بمفتاح العميل الخاص وضمن حدودها؛
7. استخدام وكلاء الذكاء الاصطناعي أو البرامج الآلية أو أتمتة المتصفح لاستكشاف ميزات الخدمة أو شاشاتها أو مسارات عملها أو محتواها أو تصميمها أو تسجيلها أو استخراجها (ويُسمح بمساعد الذكاء الاصطناعي الذي يربطه مستخدم عبر الموصل الذي ننشره ليعمل على بيانات العميل نفسه)؛
8. بناء منتج منافس أو تحسينه، أو قياس أداء الخدمة أو اختبارها لهذا الغرض؛
9. التنقيب في النصوص والبيانات على الخدمة أو الوثائق أو مواقعنا (الحقوق محفوظة — الشروط، البند 9)؛
10. تخزين **فئات خاصة من البيانات الشخصية** (الصحة، والبيانات البيومترية، والدين، والسوابق الجنائية وما شابهها)، أو أرقام بطاقات الدفع، أو **بيانات الأطفال**، ما لم يُتفق على ذلك كتابةً؛
11. استخدام الخدمة من بلد خاضع لعقوبات شاملة أو لصالح أشخاص فيه، أو لصالح أي شخص مُدرج في قائمة عقوبات (ولا يُقدَّم Curahold في إيران إطلاقًا)؛
12. مراقبة الموظفين خفيةً، أو استخدام ميزات النشاط بطريقة يحظرها القانون — يُبلغ العميل موظفيه مسبقًا ويقصر العروض على مستوى الشخص على الأدوار التي تحتاج إليها؛
13. استخدام ميزات الذكاء الاصطناعي لإنتاج محتوى غير مشروع، أو لاتخاذ قرار بشأن شخص له أثر قانوني دون قرار بشري، أو بطريقة تخالف قواعد الاستخدام لدى مزوّد النموذج.

**الاستخدام العادل.** لا عدّاد شهريًا لتشغيلات الأتمتة؛ يعالج كل تشغيل عددًا محددًا من العناصر في كل مرة، ويُعالَج الباقي في التشغيل التالي. ولواجهة API وعمليات الاستيراد والتصدير حدود لمعدل الطلبات، ولميزات الذكاء الاصطناعي حصة شهرية لكل خطة، وهي تُبقي الخدمة سريعة للجميع (موثّقة في مرجع API ومعروضة في المنتج). وقد تُبطَّأ حركة المرور التي تتجاوز الاستخدام العادي بكثير أو يُطلب نقلها إلى خطة مناسبة. وتتلقى الطلبات التي تتجاوز حدًّا ما ردًّا بـ"طلبات كثيرة جدًا" مع مدة الانتظار؛ وقد تُرفض برامج الزحف والأدوات الآلية المعروفة مباشرةً.

**ما الذي يحدث.** ننبّه أولًا ونطلب إصلاح الأمر حيث نستطيع. ويجوز لنا إزالة المحتوى، أو إبطاء الوصول أو **تعليقه** في أضيق نطاق ممكن، عندما يكون الإخلال جسيمًا أو مستمرًا، و**إنهاء** الاتفاقية عند إخلال جسيم أو متكرر (الشروط، البند 13). أبلغ عن إساءة الاستخدام على [البريد الإلكتروني لبلاغات إساءة الاستخدام].
