# المحاسبة: ملف من أي برنامج آخر

البرامج التي ليس لها API مفتوح — Logo وMikro وTally وSAP Business One وغيرها — تتصل عبر ملف. وتعمل الأرقام بعد ذلك تمامًا كبرنامج متصل: صفحة العميل والمطابقة ومؤشر الصحة.

## الخطوات

1. في **الإعدادات ← مصادر البيانات ← برامج المحاسبة**، اختر **رفع ملف**.
2. في تبويب **الرفع**، نزّل **القالب** للعملاء والفواتير والمدفوعات.
3. صدّرها من برنامجك وضعها في أعمدة القالب (Excel أو CSV؛ تُهمل الأعمدة الزائدة).
4. ارفع العملاء أولًا، ثم الفواتير، ثم المدفوعات.

## الأعمدة

| الملف | الأعمدة |
| --- | --- |
| العملاء | customer_id, name, tax_id, email, website, currency, balance |
| الفواتير | invoice_id, customer_id, number, issued_on, due_on, currency, total, balance, status |
| المدفوعات | payment_id, customer_id, invoice_id, paid_on, amount, currency |

التواريخ بصيغة YYYY-MM-DD. يمكن أن تكون `status` إحدى open أو paid أو void أو draft؛ وإن تُركت فارغة تُعدّ الفاتورة التي عليها مبلغ متبقٍ مفتوحة.

## أرقام أحدث

ارفع ملفًا جديدًا متى شئت: يحلّ محلّ الملف السابق من النوع نفسه. تبقى المطابقات اليدوية كما هي. لا يُرسل الملف إلى أي مكان آخر.
