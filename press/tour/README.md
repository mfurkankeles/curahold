# Sales-site tour GIFs

Animated walkthroughs of the Curahold sales site, one per language, for decks
and pitches (English-first, all nine languages).

- `curahold-tour-<locale>.gif` — `en, tr, ar, he, fa, zh-Hans, zh-Hant, ja, ko`
- 900×615, ~4.5s, ~5 MB each. RTL (ar/he/fa) and CJK render with their own fonts.
- Each shows the same tour: hero → Accounts board → one customer's health page →
  meeting-becomes-tasks → task board → portfolio health.

These are generated by rendering the built site (`dist/site/<locale>/index.html`)
headlessly and capturing a scroll pass — no screen recording, invented demo data
only (the same names as the demo). Regenerate after a site change on request.

Not served by the site and not part of any deploy; they live here as assets only.
